# 정부24 검색과 신청 안내 대조 (2026-11-10)

공공데이터포털 정부24 API를 2026-11-10 09:02 KST에 110쪽 전량 조회하여 총 10,942건을 받았다. 이 중 광역·기초 지자체 직접 소관 7,891건, 243개 소관기관을 수록했다. 10월 13일 저장 목록과 ID로 비교하면 25건이 추가되고 38건이 목록에서 빠졌으며 기존 ID 중 수정일시가 달라진 항목은 1,788건이다. 목록에서 빠졌다는 사실만으로 사업 폐지를 뜻하지 않는다.

정부24 서비스 목록 검색 결과와 공식 신청 안내를 대조했다. 아래는 신청서 제출이나 개인별 자격 심사를 수행한 결과가 아니다.

## 충북 군 지역 임산부 교통비

- 실제 MCP `search_gov24_services`로 `임산부 교통비`, 충청북도를 검색하여 서비스 ID `643000000739`와 [새 정부24 상세 주소](https://plus.gov.kr/portal/benefitV2/benefitTotalSrvcList/benefitSrvcDtl?svcSeq=2131916&bnefType=all&svcId=643000000739)를 찾았다.
- [충청북도 공식 공지](https://gachi.chungbuk.go.kr/portal/bbs/B0000001/view.do?menuNo=200040&nttId=868)는 진천군의 2026년 신청이 9월 14일 기준 마감됐고, 보은·옥천·영동·증평·괴산·음성은 접수를 유지하되 추가 예산 확보 전까지 심사·지급이 지연될 수 있다고 설명한다.
- [사업 안내 페이지](https://gachi.chungbuk.go.kr/portal/pbanc/pbanc06/frontView.do?menuNo=200072)는 예산 소진 지역에도 신청이 가능하다는 일반 문구를 포함한다. 이 문구와 진천군 마감 공지를 구분하고, 공지에 명시되지 않은 단양군의 현재 예산 상태는 확정하지 않는다.

## 서울 동대문구 취약계층 반려동물 의료비

- 실제 MCP `search_gov24_services`로 `반려동물 의료비`, 동대문구를 검색하여 서비스 ID `305000000130`을 찾았다.
- [정부24 상세 안내](https://www.gov.kr/portal/rcvfvrSvc/dtlEx/305000000130)는 신청기간을 예산 소진 시까지로 표시하고 지정 동물병원 방문을 안내한다. 예산 잔액이나 실제 접수 가능 여부를 확인한 것은 아니다.

정부24 링크는 실제 신청 상태를 보장하지 않으며, 소관기관의 최신 공지와 접수처 확인이 필요하다.
