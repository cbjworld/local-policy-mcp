# 공공누리 홈페이지 자료

`municipal-kogl1-20261106.json`은 아래 지자체의 공공누리 제1유형 자료 4건을 2026년 11월 6일 수집해 추출한 검색용 자료입니다. 이용 시 각 원문 출처를 표시합니다. 사업의 현재 시행·접수 여부는 원문과 별도 최신 공지에서 확인합니다.

- 구미시 형곡2동, 2024년 게시 [산후조리비 지원사업](https://www.gumi.go.kr/hyeonggok2/board/post/view.do?bcIdx=1&idx=815868&mid=0201000000), 2025년 사업 안내.
- 구미시 인구청년과, 2026년 게시 [구미형 청년월세 조기마감 안내](https://www.gumi.go.kr/portal/board/post/view.do?bcIdx=1&idx=834701&mid=0401020000).
- 성남시 분당구보건소 건강증진과, 2026년 게시 [경기도 산후조리 지원사업 종료·접수연장 안내](https://www.seongnam.go.kr/bbs010101/405225). 게시일과 수정 시점은 다를 수 있습니다.
- 안산시, 작성연도 미표시 [경기도 산후조리비 지원 안내](https://www.ansan.go.kr/iloveyou/sub/contents.do?c1=3&c3=22).

제1유형은 출처 표시 조건으로 이용할 수 있습니다. 각 항목에는 출처 URL과 원문 SHA-256, 수집 시각이 포함됩니다. 원본 HTML과 첨부파일은 포함하지 않습니다. 이 파일은 전체 보유 자료가 아니며 서버에서 자동 로드하지 않습니다.

로컬 MCP에서 사용하려면 서버 환경변수 `POLICY_MUNICIPAL_CATALOG`에 이 JSON 파일의 절대경로를 지정하고 MCP를 재시작합니다. 기존 65개 출처가 든 로컬 자료를 사용 중이라면 이 4건 파일로 바꾸지 않아도 됩니다.
