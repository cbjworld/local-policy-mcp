# 이웃정책

**전국 지자체 정책검색 MCP · 다른 지역은 어떻게 했을까?**

**[이웃정책 웹사이트 바로가기](https://ieut-policy-search.onrender.com/)** · [웹사이트 소스코드와 실행 방법](https://github.com/cbjworld/local-policy-mcp/tree/web-search/web)

웹에서는 정부24 서비스 목록과 2026년 지자체 예산을 검색하고 공식 원문을 볼 수 있습니다. 정보공개포털 문서 검색도 연결했으며, 포털 점검 중에는 연결 상태를 안내합니다.

새로운 사업을 준비할 때, AI에게 다른 지자체의 사례·계획서·예산을 찾아달라고 물어보세요.
이웃정책이 자료를 찾고 읽으면, 연결한 AI가 확인한 내용과 원문 링크를 정리합니다. 공개 원문과 비공개를 포함한 문서 목록을 자동으로 이어 검색하고, 읽지 못한 문서도 제목과 출처를 표시합니다. 결과가 길면 검색 ID로 추가 문서 목록을 나눠 확인할 수 있습니다. 저장소에 보관된 목록은 서버 재시작 후에도 열 수 있으며, 임시 보관된 목록은 재시작이나 보관 한도에 따라 사라질 수 있습니다.

MCP는 **AI에 외부 도구를 연결하는 방식**입니다. 한 번 연결해 두면 평소 말하듯 질문할 수 있습니다.

## 현재 버전과 개발 중인 기능

이 페이지는 기본 브랜치 `main`의 **v1.8.31**을 기준으로 설명합니다. 기본 브랜치에는 2026년 본예산 일반회계 세출 사업행 326,289건이 수록되어 있습니다.

[개발 브랜치](https://github.com/cbjworld/local-policy-mcp/tree/private-development-20261029)에는 지자체 홈페이지 자료와 정부24 서비스 검색, 추가 예산 자료가 반영되어 있습니다. 개발 브랜치 기준 자료는 일반회계 세출 사업행 360,699건과 2026년 11월 10일 수집한 정부24 서비스명·공식 링크 7,891건입니다. 이 숫자는 사업 전체의 건수가 아니라 각각 예산서의 사업행 수와 서비스 목록 수입니다. 제주시·서귀포시는 정부24 목록에 별도 소관기관으로 수록되지 않았습니다.

개발 브랜치의 기능과 자료는 기본 브랜치나 아래 원격 서버에 모두 반영된 상태로 간주하지 마세요.

## 이런 일을 도와줍니다

| 하고 싶은 일 | 도움받을 수 있는 내용 |
|---|---|
| 다른 지역 사례 찾기 | 광역·기초 지자체의 사업·계획 문서 검색 |
| 예산 확인하기 | 수록 예산에서 사업명·기관별 편성액과 원문 위치 조회 |
| 계획서 읽기 | 공개 PDF·HWP·HWPX에서 대상·내용·예산·기간의 근거 확인 |
| 사례 비교하기 | 사업기간·대상·지원액·사업예산을 별도 열과 원문 인용으로 비교 |
| 우리 지역 도입 검토하기 | 참고 사례에서 확인한 사실과 우리 지역에서 정할 조건 정리 |
| 예상 비용 계산하기 | 입력한 인원·지원액·횟수로 예산 시나리오 계산 |

원문 조회는 **문서의 사업비·지원금 예산·홍보비와 근거 쪽수**를 먼저 정리합니다. 산식으로 구한 금액은 계산값으로 표시하고, 원문 안의 연령 조건이 서로 다르면 해당 항목에 함께 표시합니다.

### 이미지 PDF도 읽기

검색한 계획서에 필요한 항목이 부족하면, 글자가 없는 공개 PDF의 쪽을 자동으로 이어 읽습니다. 여러 쪽짜리 이미지 계획서는 2쪽을 먼저 확인하고 부족하면 1쪽도 읽습니다. 한 질문에서 기본 2쪽을 확인하고 항목이 채워지면 멈춥니다. 다른 문서 조회 후 지원 한도만 남으면 다음 빈 쪽 1쪽을 추가로 확인합니다(총 3쪽 이내). 추가 쪽은 이렇게 요청할 수 있습니다.

> 그 첨부의 1쪽을 OCR로 읽어줘. 사업비와 지원 조건은 원본 쪽수와 함께 정리해줘.

전용 색인으로 저장된 사업명과 예산행을 빠르게 찾고, 제공기관 점검으로 열리지 않는 첨부의 중복 요청을 줄입니다. 공개 문서 검색과 전체 범위의 제목 검색을 겹쳐 기다리는 시간을 줄입니다. 텍스트 계획서를 먼저 읽고, 다음에 읽을 다른 기관의 공개 첨부도 미리 준비합니다. 비교에 필요한 정보가 부족하면 보류한 이미지 문서를 OCR로 이어 읽습니다. 조건별 지원액은 원문 조건 그대로 비교하며, 보류한 후보의 제목과 후속 조회 주소도 보존합니다. 참고 지침도 필요하면 “참고 지침도 읽어줘”라고 요청하세요. 같은 한글 파일은 원문이 동일할 때 반복 변환을 줄입니다.

OCR 결과에는 `OCR 판독값` 표시와 숫자 재검토 위치가 붙습니다. 양식·참고 지침·대상이 다른 첨부와 비공개 파일은 자동 OCR에서 제외합니다. 빠진 대상·기간·사업비·지원액은 같은 기관·부서·사업명·사업연도의 다른 문서로 최대 2건 보완하며, 문서별 출처와 서로 다른 값은 유지합니다. 제목에 연도가 없으면 본문의 사업기간까지 대조합니다.

빠른 텍스트 조회만 원하면 `research_policy` 또는 `research_open_document`에 `autoOcr: false`를 지정할 수 있습니다.

같은 파일 내용의 같은 쪽은 서버 메모리에 남은 최근 결과를 재사용합니다. 파일 내용이 바뀌면 새로 판독하며, 서버 재시작 후에는 다시 읽습니다. 본문 판독과 숫자 대조를 모두 유지합니다.

숫자 판독 결과가 다른 줄은 원본·정리 이미지로 다시 확인합니다. 두 재판독과 기존 비교 숫자·주변 문맥이 일치하고 인식 점수가 기준을 통과하면 숫자만 복원합니다. 한 쪽당 최대 4줄과 숫자 칸 8개를 재확인합니다. 감액 기호·쉼표는 원본 이미지의 모양도 대조하며, 수정 전후와 위치를 함께 제공합니다.

불확실한 금액 칸은 추가 숫자 모델로 원본·정리 이미지를 대조합니다. 감액 기호와 원문 위치를 확인하고 두 판독이 같은 숫자를 반환할 때 복원합니다. 날짜·한글 금액 단위·백분율은 한국어 모델로 필요한 칸만 추가 대조합니다. 백분율은 두 모델이 모두 같은 값으로 읽어야 채택합니다. 잘린 끝자리는 원본에 잉크가 닿은 경우에만 범위를 넓히고 표 경계에서 멈춥니다. 높게 잡힌 금액 칸은 숫자 줄을 분리해 읽습니다. 예산표는 두 이미지에서 읽은 숫자 후보와 예산액·전년도액·증감액 관계를 대조합니다. 한 가지 조합만 성립할 때 선택하고, 다른 원문 값은 유지합니다. 고정 43쪽의 숫자 정답 152개를 유지했습니다. v1.7.0은 금액·수량·주소와 한글 제목·사업명을 필요한 영역에서 추가 대조합니다. 같은 픽셀·같은 모델의 중복 계산을 재사용하고 옅은 표의 회색 선을 정리합니다. 별도 새 문서 20건의 항목별 결과와 처리 시간은 검증 기록에서 볼 수 있습니다. ## 처음 연결하기

**MCP 연결을 지원하는 AI 앱에서 서버 주소를 한 번 등록합니다.**
이웃정책에 연결하기 위한 별도 로그인·API 키는 필요하지 않습니다.

```text
https://local-policy-mcp.onrender.com/mcp
```

| 입력 항목 | 넣을 내용 |
|---|---|
| 이름 | `이웃정책` |
| 서버 주소 / URL | 위 주소를 그대로 복사 |
| 연결 방식 선택란이 있다면 | HTTP / Streamable HTTP |
| 인증 선택란이 있다면 | 인증 없음 / No sign in |

**Claude 웹·데스크톱에서 연결하는 예시**

1. Claude에 로그인하고 **Customize → Connectors**를 엽니다.
2. **+ Add → Add custom connector**를 선택합니다.
3. 이름과 위 서버 주소를 입력하고 **Continue**를 누릅니다.
4. 인증 방식을 묻는 화면에서는 **No sign in**을 선택하고 추가를 마칩니다.
5. 새 대화에서 추가한 커넥터를 사용하도록 선택하고, 도구 사용 승인이 나오면 승인합니다.

메뉴 이름과 이용 가능 여부는 앱·계정 설정에 따라 다릅니다. 조직 계정은 관리자가 커넥터를 등록해야 할 수 있습니다. [Claude 공식 연결 안내](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)

연결 후 새 대화에서 아래 문장을 입력해 도구가 실제로 보이는지 확인하세요. 연결이 확인되면 아래 질문으로 실제 검색까지 실행합니다.

> 이웃정책 MCP의 도구 목록을 확인해줘. 연결되어 있지 않으면 알려줘.

Claude Code·Cursor 사용자와 직접 설치하려는 분은 [앱별 연결·설치 안내](USAGE.md)를 참고하세요.

## 시연 전에 준비하기

시연 전에 설치 폴더의 **`START-DEMO.cmd`**를 실행하세요. 서버를 깨운 뒤 MCP 연결·원문/OCR 도구 등록·실제 예산 검색까지 확인하고 **시연 준비 완료**를 표시합니다. 준비 도구는 원문 다운로드나 OCR 자체를 실행하지 않으므로 실제 질문으로도 미리 확인하세요. 최대 2분 동안 기다리며, 확인을 마치면 자동 호출을 멈춥니다.

Node.js 22.19 이상과 이 저장소의 의존성이 필요합니다. 처음에는 `npm ci`, 이후에는 `npm run prepare:demo`로도 실행할 수 있습니다. 원격 MCP만 사용하는 분은 [서버 깨우기](https://local-policy-mcp.onrender.com/health)를 열어 `ok` 응답을 확인한 뒤 AI에서 실제 검색을 한 번 실행하세요.

무료 서버는 일정 시간 요청이 없으면 다시 잠듭니다. 시연할 질문의 원문·OCR까지 미리 확인하고, 시연 직전에 준비 기능을 다시 실행하세요.

## 첫 질문부터 업무 활용까지

아래 문장을 복사해 시작하세요. 사업명은 찾으려는 주제로 바꾸면 됩니다.

**① 사례 찾기**

> 이웃정책 MCP로 청년 면접수당 지원 사업을 찾아줘. 면접비·면접활동비도 함께 찾고, 확인한 지역과 원문 링크를 보여줘. 검색 기간과 아직 확인하지 못한 범위도 알려줘.

**② 같은 대화에서 비교 요청하기**

> 찾은 사례의 지원 대상, 지원액, 사업 예산을 표로 비교해줘. 원문을 읽은 내용과 제목으로만 찾은 내용을 구분해줘.

**③ 우리 지역 도입 검토하기**

> 우리 구에서도 도입하려고 해. 참고할 만한 운영 방식과 우리가 정해야 할 조건을 정리해줘.

**④ 예상 비용 계산하기**

> 200명에게 1인당 5만원씩 연 2회 지원하면 얼마야? 행정비용은 별도로 표시해줘.

이 계산은 입력한 조건에 따른 예상 비용입니다. 공식 편성 예산과 구분해서 보여줍니다.
검색 표현을 바꾸거나 다음 문서를 더 읽는 작업은 연결한 AI가 이어서 수행합니다. [실무 시연 가이드](DEMO.md)에서 실제 원문과 촬영 순서를 확인하세요.

## 사업비와 근거를 함께 정리합니다

- **문서의 사업비:** 원문의 사업비·소요예산·총사업비를 하나의 비교 항목으로 보여줍니다.
- **표기 금액과 계산값:** 지원금 산식은 계산값으로 구분하고, 지원금·홍보비·개인 지원액을 각각 제시합니다.
- **추가 자료 연결:** 빠진 항목은 같은 사업의 관련 문서를 최대 2건 더 읽어 출처별로 보완합니다.

원문에 별도 항목이 없으면 **별도 표기 없음**, 별표로 가려져 있으면 **가림 처리**로 표시합니다.

|---|---|
| 원문 근거 | 문서에서 읽은 내용입니다. 인용문·첨부명·원문 링크를 확인할 수 있습니다. |
| 제목으로 존재 추정 | 관련 문서 제목을 찾았습니다. 대상·금액 등 세부 조건은 별도 확인 대상입니다. |
| 미확인 | 이번에 읽은 자료에서 해당 정보를 확보하지 못했습니다. |
| 가림 처리 | 원문의 해당 내용이 별표 등으로 가려져 있습니다. |

업무 자료에 활용할 때는 **지자체명·사업연도·금액의 종류·원문 링크**를 함께 확인하세요.
사업 전체 예산, 주민 한 명의 지원액, 지자체 사이 교부금은 각각 구분합니다.
연결 근거가 확인된 광역·기초 공동사업은 한 사례로 묶고 문서별 금액을 유지합니다.

## 연결이 안 되거나 자료가 부족하다면

- **처음 응답이 늦어요.** 무료 서버가 켜지는 동안 잠시 기다린 뒤 다시 요청하세요.
- **AI가 연결된 도구가 없다고 해요.** 앱에 서버가 등록됐는지, 현재 대화에서 커넥터가 켜져 있는지 확인하세요. 설정 반영에 새 대화나 앱 재실행이 필요한 경우 앱 안내를 따르세요.
- **결과가 적어요.** “같은 사업의 다른 표현으로도 검색하고, 다음 후보 문서까지 확인해줘”라고 이어서 요청하세요.
- **예산이나 조건이 미확인이에요.** “다른 첨부와 관련 계획서를 더 확인해줘”라고 요청하세요. 읽지 못한 문서는 제목과 확인한 범위가 표시됩니다.

## 현재 제공 범위

정보공개포털의 지자체 문서를 검색하고, 공개된 PDF·HWP·HWPX의 텍스트를 읽습니다.
예산 자료는 **2026년 본예산 일반회계 세출**이며, 특별회계·기금·세입은 제외합니다.
이미지 PDF는 `read_open_document`의 `ocr: true`, 공개 첨부 ID, `page`로 읽습니다. 일반 텍스트 추출이 되면 기존 결과를 사용하고, 글자가 없는 PDF에만 OCR을 실행합니다. 로컬 설치는 `npm run prepare:ocr`로 모델을 준비하고 Python 환경에 `requirements.txt`를 설치합니다. 공개 서버는 모델을 포함해 배포합니다. 서울 외부 원문 연결 경로 개선은 후속 범위입니다.

### 검색 출처 보관

검색 결과의 출처 목록은 `list_research_sources`로 나눠 볼 수 있습니다. 저장소가 연결되어 `storage`가 `archived`로 표시된 목록은 서버가 재시작된 뒤에도 검색 ID로 다시 열 수 있습니다. 검색 ID는 목록을 여는 열쇠이므로 안전하게 보관하세요. 저장소 미설정 또는 저장 실패 시에는 `temporary`로 표시됩니다. 무료 저장소의 계정별 용량과 일일 사용량 한도가 적용됩니다.

백그라운드 검색이 연결된 서버에서는 남은 페이지를 별도 실행기가 이어서 조회합니다. `list_background_sources`로 진행 상태와 추가 문서 제목·링크를 볼 수 있습니다. 서버가 잠들거나 재시작돼도 진행 위치를 이어갑니다. 전체 작업은 하루 1,000쪽, 대기 순서 확인 8,000회, 활성 작업 20개까지 처리하며 일일 한도에 도달하면 다음 UTC 날짜에 이어갑니다. 활성 작업이 가득 차면 최대 50건이 대기합니다. 자리가 나면 다음 작업을 깨우고, 알림이 실패한 경우에는 30분 간격으로 다시 확인합니다. 포털 오류가 연속 6회 발생한 작업과 대기자가 있을 때 10쪽을 처리한 작업은 검색 위치와 수집 결과를 보존한 채 자리를 양보하고 다시 대기합니다. 접수 한도를 넘으면 시작되지 않았다고 표시합니다. 추가 검색어와 결과는 별도 Cloudflare 실행기에 저장됩니다.

직접 운영할 때는 Cloudflare Workers KV 저장소를 만들고 `POLICY_KV_ACCOUNT`, `POLICY_KV_NAMESPACE`, `POLICY_KV_TOKEN` 환경변수를 설정합니다. 토큰은 Workers KV Storage 편집 권한만 부여하고 비밀로 관리하세요. 저장되는 목록과 검색어는 검색 ID로 암호화됩니다.
