# local-policy-mcp

**지자체 정책검색 MCP · 다른 지역은 어떻게 했을까?**

새로운 사업을 준비할 때, AI에게 다른 지자체의 사례·계획서·예산을 찾아달라고 물어보세요.
정책검색 MCP가 자료를 찾고 읽으면, 연결한 AI가 확인한 내용과 원문 링크를 정리합니다.

MCP는 **AI에 외부 도구를 연결하는 방식**입니다. 한 번 연결해 두면 평소 말하듯 질문할 수 있습니다.

## 이런 일을 도와줍니다

| 하고 싶은 일 | 도움받을 수 있는 내용 |
|---|---|
| 다른 지역 사례 찾기 | 광역·기초 지자체의 사업·계획 문서 검색 |
| 예산 확인하기 | 수록 예산에서 사업명·기관별 편성액과 원문 위치 조회 |
| 계획서 읽기 | 공개 PDF·HWP·HWPX에서 대상·내용·예산·기간의 근거 확인 |
| 사례 비교하기 | 문서별 조건과 금액을 인용문·출처와 함께 비교 |
| 우리 지역 도입 검토하기 | 참고 사례에서 확인한 사실과 우리 지역에서 정할 조건 정리 |
| 예상 비용 계산하기 | 입력한 인원·지원액·횟수로 예산 시나리오 계산 |

## 처음 연결하기

**MCP 연결을 지원하는 AI 앱에서 서버 주소를 한 번 등록합니다.**
정책검색 MCP에 연결하기 위한 별도 로그인·API 키는 필요하지 않습니다.

```text
https://local-policy-mcp.onrender.com/mcp
```

| 입력 항목 | 넣을 내용 |
|---|---|
| 이름 | `local-policy-mcp` |
| 서버 주소 / URL | 위 주소를 그대로 복사 |
| 연결 방식 선택란이 있다면 | HTTP / Streamable HTTP |
| 인증 선택란이 있다면 | 인증 없음 / No sign in |

**Claude 웹·데스크톱에서 연결하는 예시**

1. Claude에 로그인하고 **Customize → Connectors**를 엽니다.
2. **+ Add → Add custom connector**를 선택합니다.
3. 이름과 위 서버 주소를 입력하고 **Continue**를 누릅니다.
4. 인증 방식을 묻는 화면에서는 **No sign in**을 선택하고 추가를 마칩니다.
5. 새 대화에서 추가한 커넥터를 사용하도록 선택하고, 도구 사용 승인이 나오면 승인합니다.

메뉴 이름과 이용 가능 여부는 앱·계정 설정에 따라 다릅니다. 조직 계정은 관리자가 커넥터를 등록한 뒤 사용할 수 있습니다. [Claude 공식 연결 안내](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)

Claude Code·Cursor 사용자와 직접 설치하려는 분은 [앱별 연결·설치 안내](USAGE.md)를 참고하세요.

## 첫 질문부터 업무 활용까지

아래 문장을 복사해 시작하세요. 사업명은 찾으려는 주제로 바꾸면 됩니다.

**① 사례 찾기**

> 정책검색 MCP로 전국의 청년 면접수당 지원 사업을 찾아줘. 면접비·면접활동비도 함께 찾고, 검색된 지자체 전체 목록과 원문 링크를 먼저 보여줘.

**② 같은 대화에서 비교 요청하기**

> 찾은 사례의 지원 대상, 지원액, 사업 예산을 표로 비교해줘. 원문을 읽은 내용과 제목으로만 찾은 내용을 구분해줘.

**③ 우리 지역 도입 검토하기**

> 우리 구에서도 도입하려고 해. 참고할 만한 운영 방식과 우리가 정해야 할 조건을 정리해줘.

**④ 예상 비용 계산하기**

> 200명에게 1인당 5만원씩 연 2회 지원하면 얼마야? 행정비용은 별도로 표시해줘.

이 계산은 입력한 조건에 따른 예상 비용입니다. 공식 편성 예산과 구분해서 보여줍니다.
검색 표현을 바꾸거나 다음 문서를 더 읽는 작업은 연결한 AI가 이어서 수행합니다.

## 사업비와 근거를 함께 정리합니다

- **계획서 사업비:** 원문의 사업비·소요예산·총사업비를 하나의 비교 항목으로 보여줍니다.
- **표기 금액과 계산값:** 지원금 산식은 계산값으로 구분하고, 지원금·홍보비·개인 지원액을 각각 제시합니다.
- **추가 자료 연결:** 빠진 항목은 같은 사업의 관련 문서를 최대 2건 더 읽어 출처별로 보완합니다.

원문에 별도 항목이 없으면 **별도 표기 없음**, 별표로 가려져 있으면 **가림 처리**로 표시합니다.

## 결과는 이렇게 읽으세요

| 표시 | 뜻 |
|---|---|
| 원문 근거 | 문서에서 읽은 내용입니다. 인용문·첨부명·원문 링크를 확인할 수 있습니다. |
| 제목으로 존재 추정 | 관련 문서 제목을 찾았습니다. 대상·금액 등 세부 조건은 별도 확인 대상입니다. |
| 미확인 | 이번에 읽은 자료에서 해당 정보를 확보하지 못했습니다. |
| 가림 처리 | 원문의 해당 내용이 별표 등으로 가려져 있습니다. |

업무 자료에 활용할 때는 **지자체명·사업연도·금액의 종류·원문 링크**를 함께 확인하세요.
사업 전체 예산, 주민 한 명의 지원액, 지자체 사이 교부금은 각각 구분합니다.
연결 근거가 확인된 광역·기초 공동사업은 한 사례로 묶고 문서별 금액을 유지합니다.

## 연결이 안 되거나 자료가 부족하다면

- **처음 응답이 늦어요.** 무료 서버가 켜지는 동안 잠시 기다린 뒤 다시 요청하세요.
- **AI가 연결된 도구가 없다고 해요.** 앱에 서버가 등록됐는지, 현재 대화에서 커넥터가 켜져 있는지 확인하세요. 설정 반영에 새 대화나 앱 재실행이 필요한 경우 앱 안내를 따르세요.
- **결과가 적어요.** “같은 사업의 다른 표현으로도 검색하고, 다음 후보 문서까지 확인해줘”라고 이어서 요청하세요.
- **예산이나 조건이 미확인이에요.** “다른 첨부와 관련 계획서를 더 확인해줘”라고 요청하세요. 비공개·이미지 문서는 제목과 확인한 범위가 표시됩니다.

## 현재 제공 범위

정보공개포털의 지자체 문서를 검색하고, 공개된 PDF·HWP·HWPX의 텍스트를 읽습니다.
예산 자료는 **2026년 본예산 일반회계 세출**이며, 특별회계·기금·세입은 제외합니다.
이미지 문서 OCR과 서울 외부 원문 연결 경로 개선은 후속 범위입니다.
