# local-policy-mcp

**지자체 정책검색 MCP**

다른 지자체의 사업·계획·예산을 원문 근거와 함께 찾고, 우리 지역에서 결정할 조건과 비용을 검토합니다.
새로운 사업을 준비하는 공무원과 정책 연구자를 위한 도구입니다.

## 주요 기능

- **도입 검토** — 참고 사례와 우리 지역의 미정 사항을 구분하고, 수록 예산에서 관련 사업명 후보를 함께 찾습니다.
- **예산 시나리오** — 사용자가 정한 인원·지원액·횟수로 연간 비용을 계산합니다. 공식 편성 예산과 계산한 예상액을 구분합니다.
- **정책 사례 검색** — 정보공개포털에서 지자체 사업·계획 문서를 찾습니다.
- **원문 읽기** — PDF·HWP·HWPX에서 계획, 예산, 지원 조건을 확인합니다.
- **예산 검색** — 2026년 본예산 일반회계 세출의 사업별 편성액을 조회합니다.
- **사례 비교** — 광역·기초 문서에서 같은 사업의 연결 근거가 확인되면 한 사례로 묶고, 기관별 역할과 문서별 예산을 원문 인용과 함께 비교합니다.
- **근거 요약** — 본문을 읽은 자료부터 대상·내용·예산·기간과 원문 위치를 보여줍니다.

## 연결하기

Streamable HTTP를 지원하는 AI 앱에 아래 주소를 등록하세요.
로그인이나 별도 API 키 없이 연결할 수 있습니다. 무료 서버는 미사용 후 첫 연결 때 기동 시간이 필요합니다.

```text
https://local-policy-mcp.onrender.com/mcp
```

서버 이름: `local-policy-mcp` · 연결 방식: `Streamable HTTP`

Claude Code·Cursor 연결 방법은 [앱별 연결 안내](USAGE.md#claude-code)를 참고하세요.

## 이렇게 질문하세요

> 우리 구도 산후조리비 지원사업을 하려는데?

> 지원 인원을 100명·200명·300명으로 나눠서, 1인당 50만원을 연 1회 지원하는 비용을 계산해줘. 기타 비용은 아직 미정이야.

> 다른 지자체 산후조리비 지원 사업의 계획과 예산을 비교해줘.

> 청년 AI 구독료 지원 사업을 찾아줘. 원문도 함께 보여줘.

> 다른 지역 빈집 정비 사업의 편성 예산을 찾아줘.

## v0.7.3 업데이트

한 번의 문서 조사 안에서 상세정보와 가장 최근에 받은 첨부파일을 재사용해 중복 요청을 줄입니다. 다른 사용자·조사 사이에는 공유하지 않습니다. 시설 사업의 설치대상·위치·개요와 지원금액·한도·신청자격을 읽고, 핵심 근거가 있는 사례부터 보여줍니다.

### v0.7.2

주민 사업 검색에서 직원 건강·후생 문서를 분리하고, 줄바꿈·글머리표로 적힌 지원내용과 지원방법·접종 대상/비용·신청기간의 근거 추출을 보완했습니다. 같은 공개 원본 6개를 재처리한 결과 대상·지원·예산·기간의 근거가 채워진 항목은 24칸 중 15칸에서 20칸으로 늘었습니다. 이는 정확도 점수가 아닌 근거 추출 항목 수입니다.

## 자체 운영 성능 설정

Docker 이미지는 배포할 때 예산 검색 색인을 생성하고 Poppler로 PDF 텍스트를 추출합니다. OCR은 사용하지 않습니다.
로컬 실행은 `npm run prepare:index`로 색인을 생성할 수 있습니다. 예산 자료를 교체하면 색인을 다시 생성하세요.
Poppler의 `pdfinfo`·`pdftotext`가 설치된 환경에서는 `POLICY_PDF_ENGINE=poppler`로 빠른 PDF 읽기를 활성화할 수 있습니다. 검색어를 지정한 PDF 조회는 기존 pypdf 경로를 사용합니다.
