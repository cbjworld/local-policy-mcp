# local-policy-mcp

지자체 정책검색 MCP

**다른 지자체의 사업·계획·예산을 찾는 MCP**

## 다른 지자체는 어떻게 했을까?

정보공개포털의 지자체 사업 문서를 AI에서 검색하고, **계획·예산·지원 조건을 원문 근거와 함께 확인**합니다.

새 사업을 준비하며 다른 지역 사례를 찾는 공무원과 정책 연구자를 위한 도구입니다. 문서 검색과 첨부파일 읽기를 연결해, AI와 대화하면서 사례를 비교할 수 있습니다.

**공개 베타 MCP · 원격 연결 / 로컬 실행 · PDF / HWP / HWPX 텍스트 읽기**

원격 MCP 주소: `https://policy-mcp-production.up.railway.app/mcp`

Streamable HTTP 지원 앱에서 서버 주소로 등록하세요. 인증은 로그인 없음이며 별도 API 키가 필요하지 않습니다. 체험 서버로 운영 중이므로 지속적인 가용성은 보장하지 않습니다.

## 이렇게 질문하세요

> 다른 지자체 산후조리비 지원 사업 찾아줘.
>
> 지원금과 사업 예산, 거주 조건을 비교해줘.
>
> 계획 중인 사업은 따로 보여줘. 원문 근거도 보여줘.

제목에서 사업 존재가 추정되면 비공개·읽기 실패 문서도 포함합니다. **제목 근거**, **본문 근거**, **미확인 정보**를 구분하며, 계획안이 현재 시행이나 예산 확정을 뜻하지는 않습니다.

## 설치

Node.js 22.19 이상, Python 3.10 이상, Git이 필요합니다. stdio MCP를 지원하는 AI 앱에서 실행합니다. 서버 자체는 AI 답변을 생성하지 않으며 연결한 AI가 근거를 해석합니다.

```sh
git clone https://github.com/cbjworld/local-policy-mcp.git
cd local-policy-mcp
npm ci --ignore-scripts --omit=optional
python -m venv .venv
```

Windows:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

macOS/Linux에서는 위의 `python` 대신 `python3`로 환경을 만들고 다음을 실행하세요.

```sh
.venv/bin/python -m pip install -r requirements.txt
```

AI 앱의 MCP 설정에 아래 항목을 추가합니다. 두 경로는 실제 설치 폴더의 **절대 경로**로 바꾸세요. macOS/Linux의 Python 경로는 `/설치폴더/.venv/bin/python`입니다.

```json
{
  "mcpServers": {
    "local-policy-mcp": {
      "command": "node",
      "args": ["--use-system-ca", "C:/설치폴더/local-policy-mcp/mcp.js"],
      "env": {
        "POLICY_PYTHON": "C:/설치폴더/local-policy-mcp/.venv/Scripts/python.exe"
      }
    }
  }
}
```

앱을 완전히 종료한 뒤 다시 실행하고 `research_policy`로 질문하세요. `npm start`는 stdio 요청을 기다리므로 화면에 아무것도 나오지 않는 것이 정상입니다.

## 원격 연결

연결 주소는 `https://policy-mcp-production.up.railway.app/mcp`입니다. 웹페이지 주소가 아니라 AI 앱에 등록하는 MCP 주소입니다. 인증은 로그인 없음(No authentication), 연결 방식은 Streamable HTTP입니다. OAuth 로그인은 제공하지 않습니다. 공식 MCP SDK로 원격 연결을 검증했으며 개별 AI 앱의 연결 화면과 지원 여부는 별도 확인이 필요합니다. 직접 운영하려면 [원격 서버 배포 안내](REMOTE.md)를 참고하세요.

## 제공 도구

### 일반회계 예산 검색 — 로컬 개발본

`search_budget_projects`는 2026년 130개 지역의 일반회계 세출사업 204,059행(지역·부서별 부분 확보)을 검색합니다. `q`에는 `산후`, `청년 주거`처럼 짧은 사업명 키워드를 넣습니다. 공백으로 나눈 키워드는 모두 포함해야 하며, `institution`으로 지역을 좁히고 `offset`과 `limit`으로 이어서 조회합니다. 기본 10행, 최대 20행을 반환합니다.

금액 단위는 **천원**이며 편성액입니다. 1인당 지원금이나 집행액이 아닙니다. 공식 원문 URL과 PDF 쪽수를 함께 반환합니다. 계획·대상·시행 여부는 `research_policy`로 추가 조사하세요.

전국 자료가 아니며 양평·특별회계·기금·세입은 제외했습니다. 총괄표 합계는 일치하지만 사업명 잘림과 의미 검증은 미완료입니다. 검색 결과가 없다고 해당 사업이 없다고 판단하면 안 됩니다. 이 추가 기능은 원격 서버 배포 확인 전인 로컬 개발본입니다.

| 도구 | 역할 |
|---|---|
| research_policy | 짧은 질문으로 검색·선별·일부 원문 조회 |
| search_open_documents | 기간·페이지·공개 범위를 지정한 문서 검색 |
| research_open_document | 첨부 선택 및 근거 후보 추출 |
| read_open_document | 특정 첨부·페이지 조회 |
| read_official_source | 공식 URL 텍스트 조회 |
| research_official_notice | 공식 공고 및 직접 연결된 첨부 조회 |
| build_research_brief | 읽은 원문의 인용문 일치 확인과 비교 초안 |

## 범위와 한계

- 기본 검색 기간은 최근 2년입니다. `research_policy`는 검색어 최대 3개, 각 원문공개 목록 2페이지, 원문 최대 4개를 조회합니다. 후보가 없으면 검색어마다 전체 공개목록 1페이지를 추가 조회합니다(검색 요청 최대 9회). 전국 전수검색이 아닙니다.
- 비공개 본문을 우회하지 않습니다. `search_open_documents`의 `scope: "all"`은 비공개 문서의 공개된 목록 정보도 찾습니다. 기본 검색은 원문공개 목록 중심입니다.
- OCR은 없습니다. 이미지 PDF·암호화·다운로드 불가 파일은 읽지 못할 수 있습니다. PDF는 일부 페이지만 반환할 수 있고 HWP의 쪽 번호는 제공하지 않습니다.
- 표 해석·사업 귀속·관련성은 휴리스틱과 연결한 AI의 판단에 의존합니다. 읽기 성공이나 인용문 일치는 사실 정확성 보증이 아닙니다.
- 계획액·본예산·추경 요구·집행액과 다른 지역 참고 금액을 구분해야 합니다. 최신 변경·종료 여부는 별도 확인하세요.
- 문서는 HTTPS 공식 도메인으로 제한하고 다운로드 크기·시간을 제한합니다. 외부 문서를 로컬 파서로 처리하므로 격리된 일반 사용자 환경에서 실행하는 것을 권장합니다. 원문은 AI 앱에 전달되며 해당 앱의 데이터 처리 정책이 적용됩니다.
- 웹사이트 전체 검색, 정부24 다운로드 데이터, 기존 웹 UI는 이 공개판에 포함하지 않습니다.

## 검증

```sh
npm test
```

합성 입력 기반 회귀 검사와 stdio·HTTP 연결 검사를 실행합니다. 이 자동 테스트는 전국 검색 정확도를 측정하지 않습니다. 2026년 10월 14일 Railway Linux 컨테이너의 HTTPS 주소에서 7개 도구 조회, 정보공개포털 검색, 인제군 PDF·HWPX와 경기도 HWPX 읽기를 별도 확인했습니다. 장시간·다중 사용자 부하 및 개별 AI 앱 호환성은 미검증입니다.

초기 내부 실험에서 새로운 질문 10개 중 8개에 유용한 정책 근거를 찾았지만, 같은 AI가 검토한 소규모 실험이므로 정확도 80%라는 의미가 아닙니다.

## 기여와 라이선스

오류나 개선 의견은 [Issues](https://github.com/cbjworld/local-policy-mcp/issues)에 남겨주세요. API 키, 개인정보, 비공개 원문은 올리지 마세요.

코드는 MIT 라이선스입니다. 공공 문서는 배포하지 않으며 원문 이용조건은 제공기관의 조건을 따릅니다. HWP/HWPX 처리는 MIT 라이선스의 Kordoc, PDF 처리는 pypdf를 사용합니다. 의존성은 각자의 라이선스를 따릅니다.


## 조사 범위와 응답 방식

research_policy는 검색어별 최대 4페이지를 직접 조회합니다. 첫 조사는 기본 후보 최대 6건과 보완 문서 1건으로 원문 최대 7건이며, 남은 페이지는 coverage.nextSearches로 이어서 확인합니다. 전국 전수조사가 아닙니다.
기본 응답은 compact이며 문서를 한 목록으로 통합하고 최대 24,000자로 제한합니다. 생략한 문서·상세 근거 수를 responseSize에 표시합니다. 연결 앱이 파일로 저장하는 기준은 별개입니다. 전체 조사 데이터는 detail: full로 요청하거나 개별 문서를 research_open_document로 조회합니다.
financialDocuments는 예산·교부·예탁·집행 문서를 따로 보여줍니다. 교부나 예탁을 실제 집행·현재 시행으로 단정하지 않습니다.
possibleProjectLinks는 일부 명시적인 지역 사업명과 연도가 같은 기관 간 문서의 연관 후보입니다. 자동으로 사업을 합치거나 중복 사업 수를 확정하지 않습니다.
원격 서버는 세션별 순차 처리하며 최대 4개 요청을 15초까지 대기시킵니다. 한도 초과 시 재시도가 필요합니다.

## 사업별 예산 자료 확인 범위

기존 4개 지역 7,541행과 새로 대조한 6388개 부서의 196,518행을 검색합니다. 새 자료는 사업행 산술과 부서 합계 대조를 통과한 자료이며, 서울시 본청은 별도 공식 총액 및 사업명·금액 전수 대조를 적용했습니다. 지역별 일부 부서는 미확보·검토 중일 수 있습니다.

PDF는 공식 원문 쪽수, 한글 문서는 원문 링크와 추출표·행 위치를 제공합니다. 한글 실제 쪽수·사업의 현행 시행 여부·지원금 단가는 별도 확인이 필요합니다. 지자체 전체 총액은 `search_verified_budget_totals`로 별도 조회합니다.

서울시 본청 별도 양식은 일반회계 지출코드와 사업행 산술을 확인하고, 추출 합계를 공식 당초 일반회계 총액에 대조한 뒤 각 사업명·금액을 별도 공식 자료와 대조했습니다. 지출목 없는 0원 사업 등은 미포함입니다.

검색 자료는 `budget-data.json.gz`에 손실 없이 압축해 배포합니다. 서버가 자동으로 읽으므로 별도 압축 해제는 필요하지 않습니다.
