# 운영 상태와 비공개 개발본 확인

2026년 11월 3일 기존 운영 서버의 상태 주소를 한 번 조회해 HTTP 200을 받았고 약 0.87초가 걸렸습니다. 별도 검색 없이 MCP 초기 연결을 한 번 요청해 HTTP 200을 받았고 약 0.39초가 걸렸으며 서버는 v1.8.31을 반환했습니다. 연속 1회 측정으로, 최초 기동·검색·문서 읽기 속도를 뜻하지 않습니다.

최신 개발 자료는 비공개 개발 브랜치에 있으며 운영본에 자동 반영된 것으로 판단하지 않습니다. 실제 Cloudflare 계정 무료 사용량을 소진하거나 운영 서버를 재시작하는 시험은 하지 않았습니다. 앱 자체 한도의 격리 시험 결과와 관측되지 않은 부분은 [별도 기록](daily-quota-live-validation-20261102.md)에 있습니다.

안산시 예산서 첨부 및 추출 데이터의 공개 검색·제공 조건은 [별도 기록](ansan-use-conditions.md)대로 확인 중입니다. 외부 기관에 문의하거나 신청하지 않았습니다.
