# 실무 질문의 예산·계획서 연결 확인

2026년 11월 3일 개발본을 로컬 MCP stdio로 연결해 실제 도구를 호출했습니다. 아래 시간은 각 호출 1회의 로컬 측정이며 AI 답변 생성 시간과 사람의 직접 검색 시간은 포함하지 않습니다.

| 확인할 업무 | 결과 | 도구 응답 |
|---|---|---:|
| 영동군 전세보증금 반환보증료 사업 예산과 계획 확인 | 1,200천원, 예산서 44쪽과 보관한 계획서 근거 링크 반환 | 예산 검색 133ms |
| 광명시 여성청소년 생리용품 저소득·보편 지원 비교 | 저소득층 122,152천원과 보편지원 1,186,248천원을 별개로 반환, 예산서 488쪽과 계획서 링크 확인 | 예산 검색 5ms |
| 광명시 계획서 원문 다시 읽기 | 공개 HWPX 본문을 읽고 두 사업 금액을 확인 | 1,802ms |

영동군 계획서는 이번 실시간 재조회 시 제공기관 점검으로 다운로드에 실패했습니다. 검색에서 반환한 근거는 앞서 성공적으로 읽어 보관한 자료이며, 이번 재조회가 성공했다는 뜻은 아닙니다. 사람의 직접 검색 시간은 측정하지 않았으므로 두 방식의 시간 절감률은 계산하지 않습니다. 원문과 세 사업의 연결 근거는 [별도 대조 기록](catalog-evidence-validation-20261103.md)에 있습니다.

광명 계획서에는 737,016천원이라는 별도 금액도 표기되어 있어 두 사업의 본예산과 구분해 확인합니다.
