# 대구 북구·경상북도 본예산 추가 대조

- 대구 북구 [일반·특별회계 합본](https://www.buk.daegu.kr/cmsh/buk.daegu.kr/file/budget_2026_1/7.pdf)의 정책소통과 13행과 정보통신과 19행을 두 PDF 추출 방식 및 원문 이미지와 대조했습니다. 올해 합계는 각각 1,042,558천원·4,153,766천원으로 부서 총액과 같고 증감액도 일치합니다. 정보통신과 수록 행의 전년도액 합계 3,780,909천원과 부서 전년도 총액 3,815,909천원의 차이는 원인을 확인하지 못했습니다. 특별회계 표시와 총액의 분리 근거는 [혁신전략과 대조](daegu-buk-innovation-validation-20261103.md)에 기록했습니다.
- 경상북도 [APEC준비지원단 예산서](https://gb.go.kr/Main/budget/2026/bon/11050020.pdf) 5쪽의 기획행사·운영지원·의전홍보·대외협력 4개 부서, 각 2행을 이미지와 대조했습니다. 올해 부서 합계가 각각 원문과 같으며 네 부서의 합 1,353,591천원은 실국 총액과 같습니다. 수록 행의 전년도액 합계는 각 부서 전년도 총액과 다르며 원인을 확인하지 못했습니다.
- 확인한 위치에서 0원 세부사업 후보를 발견하지 못했으나, 다른 배치나 윤곽선만으로 된 글자의 누락은 별도 검토가 필요합니다. 두 기관의 관련 원문·추출자료 공개 제공 조건도 확인 중이므로 비공개 개발 자료로 관리합니다. 원본 PDF는 저장소에 넣지 않습니다.

## 대구 북구 기획예산과 추가 검증

2026년 일반회계 세출 명세서 1~11쪽에서 25행을 수록했다. 각 행의 전년도 대비 증감을 대조했고 올해 합계 4,518,393천원과 전년도 합계 5,302,162천원이 부서 총액과 각각 일치한다. 9쪽의 `인력운영비` 두 행은 각각 70,000천원과 324,565천원으로 상위 단위가 다르다. 사업 목록에서는 같은 이름으로 묶일 수 있으므로 두 행을 별도 예산 기록으로 보존하며 자동 합산하지 않는다. 원문은 [대구 북구 본예산 명세서](https://www.buk.daegu.kr/cmsh/buk.daegu.kr/file/budget_2026_1/7.pdf)이며 SHA-256은 `3426afb94becfa25e3da1a0bc9e669b95a0a33997eda44cbdc4feca9a494cc97`이다. 표의 비표준 배치에 따른 0원 사업 누락 가능성과 공개 재이용 조건은 별도 확인이 필요하다.
