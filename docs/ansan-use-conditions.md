# 안산시 예산 자료 이용 조건 확인 기록

- [공식 2026년 본예산 게시물](https://www.ansan.go.kr/www/common/bbs/selectBbsBudgetBookDetail.do?bbs_code=WWW22&bbs_seq=1658773)에 공공누리 제3유형 표시와 일반회계 예산서 첨부 링크가 함께 있습니다.
- [공공누리 공식 안내](https://www.kogl.or.kr/info/userGuide.do)의 제3유형 조건은 출처표시와 변경금지이며 상업적 이용 자체는 가능합니다.
- [공공누리 이용약관](https://www.kogl.or.kr/info/license.do)은 변경금지 조건에 내용과 형식의 변경을 포함합니다. [공공누리 개방지원센터 답변](https://www.kogl.or.kr/info/userQnaView.do?dataIdx=2618)은 제4유형 공문서 일부를 화면에 노출하는 사례에서 변경금지 여부와 별도 이용허락을 설명합니다. 제4유형의 원문 일부 노출 사례이므로 제3유형 예산서의 사업명·금액 색인에 그대로 적용하거나 금지라고 단정할 수는 없습니다.
- 게시물의 표시가 첨부 PDF 전체와 사업명·수치 발췌 및 전체 목록의 검색·제공에 어떤 범위로 적용되는지, 예산서의 편집물이나 데이터베이스 권리가 관련되는지는 확인되지 않았습니다. 사실정보 추출이 반드시 허용되거나 금지된다고 판단하지 않습니다.
- 같은 게시물의 일반회계 세출 PDF 1,069쪽 텍스트에서 공공누리·저작권·이용허락·변경금지·출처표시 문구는 발견되지 않았고 임베디드 이미지와 제목·작성자 메타데이터도 없었습니다. 이는 벡터 표시까지 없거나 게시물 조건이 첨부에 적용되지 않는다는 증거는 아닙니다. [안산시 저작권정책](https://ansan.go.kr/www/common/cntnts/selectContents.do?cntnts_id=C0001386)은 공공누리 미부착 자료 이용 시 담당자와 사전 협의를 안내합니다.
- [공공누리 자주 묻는 질문](https://www.kogl.or.kr/info/faqList.do?dataGroup=2&mstIdx=KOGL_019)은 조건을 넘어 이용하려면 제공기관에 문의하도록 안내합니다. 공개 서비스에 대량 제공하기 전 안산시에 첨부 PDF와 사업명·편성액 추출 데이터의 검색·상업적 제공 범위를 확인합니다.
- 확인할 항목: 게시물 표시가 첨부에 적용되는지, 사업명·예산액·원문 쪽수를 검색 색인에 보관하고 공개할 수 있는지, 전체 목록 또는 일부 제공과 상업적 이용에 별도 조건이 있는지. 원문 PDF는 저장소에 포함하지 않습니다.
- 비교 가능한 [지방재정365 세부사업 세출현황 API](https://www.data.go.kr/data/15138857/openapi.do)는 무료이며 이용허락범위 제한 없음으로 표시되고 운영단계는 심의승인입니다. 제공 항목은 예산현액과 집행현황이며 본예산 편성액과 구분해야 합니다. 2026년 응답과 조회 범위는 아직 실호출로 검증하지 않았습니다.
