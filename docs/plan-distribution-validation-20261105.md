# 계획 안내 문서 분류 검증

실제 `반려동물 의료비 지원` 검색에서 대구광역시 추진계획과 대구 동구의 `추진계획 안내 및 협조 요청`, 달성군의 `추진계획 알림 및 홍보 요청`이 각각 독립 사업 후보로 제시됐다. 제목만으로 동일 사업을 확정할 수는 없으나, 안내·협조 요청을 생산기관의 독립 계획으로 취급할 근거도 없다.

이 두 형태의 제목은 보조 문서로 분류해 출처를 남기고, 원래 계획 제목은 사업 후보로 유지한다. 사용자가 협조·홍보 문서를 직접 요청한 경우는 기존 분류를 유지한다. 실제 검색 결과의 제목으로 자동 시험을 작성했다. 원문을 읽거나 두 기관의 사업이 동일하다는 사실을 확인한 시험은 아니다. 포털 요청 제한이 발생해 같은 검색을 재호출하지 않았다.
