# 사업연도와 대상 불일치 검증 — 2026-11-05

정보공개 문서의 제목 연도와 본문 사업기간 연도를 별도 필드로 보존한다. 본문의 `사업기간` 근거에서 하나의 연도만 확인될 때 사업연도를 표시하고, 제목 연도와 다르면 비교 검토 표시를 남긴다. 여러 연도가 함께 적힌 기간은 단일 연도로 축약하지 않고 참고 지침의 인용은 자체 사업연도 근거로 사용하지 않는다. 사업 묶음의 기존 식별 기준을 사업연도로 바꾸지는 않는다.

대구 남구 [청년 부동산 중개보수 및 이사비 계획](https://www.open.go.kr/othicInfo/infoList/infoListDetl.do?prdnNstRgstNo=DCT82F32F98DA35FF352F54484F34A03594&prdnDt=20261022175159&nstSeCd=B)을 실제로 읽어 본문 사업기간 2027년(1·2쪽), 소요예산 60,000천원(1·2쪽), 지원 한도 최대 30만원(2쪽)을 확인했다. 2026년에 작성된 문서이므로 이 계획금액을 2026년 본예산 편성액으로 표현하지 않는다. 해당 원문을 읽은 실제 MCP 결과를 새 비교 로직에 적용한 결과 짧은 응답에서도 2027년과 원문 쪽수가 유지됐다. 2027년 예산 편성이나 현재 시행 여부를 확인한 것은 아니다.

요청 대상과 명시적으로 맞지 않아 제외된 첨부, 요청 대상에 맞지 않는 문서, 보조 문서를 직접 예산 연결 근거로 승격하지 않도록 했다. 대조 가능한 금액과 기관·연도가 같더라도 대상 불일치를 우선한다. 합성 표를 이용해 각 제외 조건과 기존 정상 교부 근거 유지 여부를 자동 시험했다. 보조 문서 직접 연결을 보수적으로 보류하므로 추가 확인할 자료가 남을 수 있다. 실제 두 문서 조회와 자동 회귀 시험을 별도로 기록하며 새로운 대상 불일치 문서를 직접 입수해 재현한 것은 아니다.
