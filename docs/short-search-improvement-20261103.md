# 짧은 업무 질문 검색 검증 — 2026-11-03

- 변경: 이사비 질문에서 원래 검색어를 유지하고 이사비용·이사 지원 표현을 최대 3개까지 사용한다. 이사비·면접비·보증료처럼 `지원`이라는 단어가 없는 질문도 문서의 사업비와 개인별 지원액이 빠졌는지 확인해 보완을 시도한다. 문서 원본 주소가 다르지만 정보공개포털 식별번호·생산시각·구분이 같은 경우에는 같은 원문으로 표시한다. 서로 다른 시각·기관 문서는 합치지 않는다.
- 실측: 개발 브랜치의 로컬 MCP에서 2026-01-01~2026-10-31, OCR 제외, 질문당 1회 실행했다. AI 답변 생성시간과 원격 서버 시작시간은 포함하지 않는다. 결과 수는 검출된 문서·후보이며 실제 시행 사업 수가 아니다.
- `청년 이사비 찾아줘`: 16.409초, 세 표현을 사용했다. 88쪽을 조회했고 623개 중복 제거 문서를 수집했으나 3개 검색 표현에서 후속 페이지가 실패해 전체 범위를 확인하지 못했다. 7개 문서 조회 중 1개에서 텍스트를 추출했다. 대구 남구 자료의 지원액 후보 최대 30만원은 추출되었고, 사업비는 읽은 범위에서 찾지 못해 추가 문서를 조회했으나 보완하지 못했다. - `청년 면접비 찾아줘`: 6.968초, 면접수당·면접비·면접활동비를 검색했다. 7쪽·38개 중복 제거 문서를 수집했고, 두 표현에서 후속 페이지가 실패했다. 5개 문서 조회 중 2개에서 텍스트를 추출했다. - 같은 원문 주소 중복 제거, 서로 다른 기관·날짜 분리, 짧은 질문에서 누락된 지원액을 같은 기관·연도·사업 문서로 보완하는 흐름은 자동화된 회귀 시험으로 확인했다. 실제 두 질문에서 동일 사업 원문 문서의 성공적 보완이나 광역·기초 연결 사례는 새로 검증되지 않았다.
- 검색 페이지 실패와 이용할 수 없는 첨부가 남아 있다. 실패를 결과 없음으로 취급하지 않으며, 누락 예산은 0원으로 처리하지 않는다. 공개 운영 서버에는 이 변경을 배포하지 않았다.
