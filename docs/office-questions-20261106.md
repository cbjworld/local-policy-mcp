# 실무 질문 검색 검증

2026-11-06, 저장된 지자체 홈페이지 70개 출처를 대상으로 검색어 계획과 홈페이지 검색을 확인했다. 정보공개포털은 실패를 모의해 저장 자료의 보완 동작을 별도로 확인했다. 실시간 전국 검색이나 결과 전체의 정답률을 측정한 시험은 아니다.

실무 표현 10개 중 홈페이지 후보가 하나 이상 나온 질문은 수정 전 7개, 수정 후 10개였다. 후보 수는 사업 수가 아니다. 검색어에 ‘시행한 곳’, ‘지원하는 지자체’, ‘다른 지역’이 남던 세 질문을 수정하고, 반려동물 의료비 질문은 의료서비스와 의료 지원 표현을 추가했다.

- 청년 이사비: 실제 [용인시 안내](https://www.yongin.go.kr/user/bbs/BD_selectBbs.do?q_bbsCode=1020&q_bbscttSn=20260707075005612)가 검색된다. 다자녀 가정 등 청년 대상이 확인되지 않은 후보는 대상 미확인으로 유지했다.
- 반려동물 의료비: 실제 [용인시 안내](https://www.yongin.go.kr/user/bbs/BD_selectBbs.do?q_bbsCode=1001&q_bbscttSn=20260204142833457&q_clCode=1)가 검색되며 돌봄 취약가구 조건을 유지한다.
- 산후조리비: 저장된 지자체 자료와 경기도 사업 관련 문서 묶음이 검색된다.

그 밖에 청년 자격증 응시료, 빈집 정비 예산, 공예기업 지원, 노인 운전면허 반납, 청년 월세, 경기도 산후조리비와 지자체 사례 질문을 확인했다. 모든 후보를 원문과 전수 대조한 것은 아니다.

## 원래 질문의 대상 유지

검색어 확장 과정에서 대체 검색어에 연령 표현이 빠져도 홈페이지 결과와 예산 연결 결과에 원래 질문의 대상 판단을 적용한다. 명시된 연령이 다르면 `target_mismatch`, 발췌문에서 확인되지 않으면 `target_unconfirmed`로 유지한다. 발췌문에 연령 표현이 있다는 것만으로 지원 자격을 확정하지 않는다.

정보공개포털 실패를 모의하고 실제 저장 자료로 확인한 결과, 청년 이사비 질문에서 용인시 청년 안내는 관련 후보로 남고 구미시 다자녀 안내와 부산 서구 기초수급자 안내는 청년 대상 미확인으로 구분됐다. 어르신 운전면허 질문에서는 칠곡군 고령자 안내가 대체 표현으로 검색됐다. 이 시험은 로컬 발췌문 기준이며 전국 결과의 정확도를 뜻하지 않는다.

## 지원대상과 서비스 내용 분리

- 청년 월세 질문에서 [노원구 1인가구 전월세 안심계약 서비스](https://www.nowon.kr/www/info/info2/info2_09/info2_09_01.jsp)는 본문의 청년 대출 정보 언급 때문에 청년 대상 월세 지급사업처럼 보일 수 있었다. 명시된 사업대상은 1인가구이므로 청년 대상은 미확인으로 표시하고, 계약 상담·동행은 월세 지급과 구별한다. 더 직접적인 청년 월세 후보를 먼저 제시한다.
- 장애인 반려동물 의료비 질문의 [용인시 안내](https://www.yongin.go.kr/user/bbs/BD_selectBbs.do?q_bbsCode=1001&q_bbscttSn=20260204142833457&q_clCode=1)는 명시된 지원대상에 중증장애인을 포함하며 소득·거주 등 조건이 있다. 대상 문구를 그대로 유지하고 모든 장애인이 대상이라고 확대하지 않는다. 장애인이 다른 문맥에만 등장하는 모의 자료는 대상 미확인으로 남겼다.
- 어르신 일자리와 어린이 예방접종 질문으로도 실제 저장 안내를 확인했다. 홈페이지 발췌문과 모의 포털 실패를 사용한 검증이며, 실시간 전국 검색은 아니다.

## 실제 포털 조회와 지급 문서 구분

2026-11-09 연결된 비공개 MCP에서 ‘아동 무료 예방접종 지원 사례’를 실제 조회했다. 약 61.5초가 걸렸고 일부 페이지 검색과 원문 파일 요청이 시간 초과됐다. 저장된 의왕시 예방접종 안내는 반환됐다. 지급 관련 문서 3건은 본문을 읽지 못했으며, 제목만으로 집행 완료를 확인하지 않았다.

기존에 일반 문서로 표시되던 ‘접종 비용 지급’과 ‘백신 대금 지급 건의’를 각각 지급 관련 문서와 지급 건의로 구분한다. 지급계획·교부·집행실적의 기존 분류는 유지하며, 제목만으로 실제 지급을 확정하지 않는다.

사전 조회의 시간 초과 재시도를 겹쳐 실행하는 시험도 같은 질문으로 한 번 수행했다. 약 60.9초가 걸렸고 읽기를 시도한 문서 수가 달라 직접적인 속도 향상으로 비교할 수 없었다. 이 실험 코드는 적용하지 않았다. 포털 파일 요청 시간 초과와 실패 페이지 재시도는 남은 과제다.

### 2026-11-09 원문 연결 실패 표시 점검
- 실제 예방접종 지원 검색에서 포털 원문 요청이 시간 초과되어 읽지 못한 문서가 발생했다. 읽지 못한 상태를 원문에 예산 표기가 없는 상태로 표시하던 문제를 수정했다.
- 읽은 본문이 없을 때는 `not_read`와 ‘원문 미확인’을 표시하고, 읽은 범위에 값이 없을 때는 `not_stated`를 유지한다. 다른 문서 보완 대상에서도 두 상태를 처리한다.
- 같은 질문의 재시도는 약 61초였고, 사전 요청 실험에서 유의미한 속도 단축은 확인되지 않아 적용하지 않았다. 시간은 해당 시험의 관측값이다.
- 전체 자동 검증 통과. 실제 포털의 원문 연결 실패가 해결됐다는 뜻은 아니다.

- 여러 첨부 중 일부만 읽고 다른 첨부가 실패한 경우, 읽은 문서만 완독했다는 이유로 전체 읽기 완료나 전체 미기재로 표시하지 않도록 수정했다. 실제 금액·가림 표시와 양식·참고자료 구분을 유지한다.

## 홈페이지 원문 변경 점검

`node --use-system-ca municipal-refresh-check.cjs 자료.json 보고서폴더 [개수] [시작위치]`로 등록된 공식 홈페이지를 확인한다. 한 번에 최대 10개를 처리하며 반환된 `nextOffset`으로 다음 범위를 이어간다. 각 사이트의 robots 규칙과 요청 간격을 지키고, 기존 페이지와 바이트 해시가 다르면 변경 후보로 기록한다. 바이트 차이는 내용 변경을 뜻하지 않을 수 있다. 접근 실패, 차단 또는 변경 후보는 기존 검색 자료를 덮어쓰지 않으며 이용 조건과 본문을 재확인한 뒤 반영한다. 이 도구는 주기적 실행을 자동으로 예약하지 않는다.

2026-11-09 첫 10개 출처의 변경 점검에서 원본 바이트 일치 1, 차이 4, 접근 제한·실패 5였다. 차이는 내용 변경 여부를 별도로 확인해야 한다. 남은 60개는 미조회다. 연결된 비공개 MCP는 70개 출처·41개 기관을 보고했고, Render 원격 MCP는 홈페이지 검색 도구를 제공하지 않아 같은 자료가 연결된 것으로 판단하지 않았다.
