# 대구 서구 청년월세 자료 대조 후보

대구 서구 교육지원과의 2026년 본예산 PDF 15쪽에는 ‘청년월세 한시 특별지원’ 684,000천원이 기재되어 있습니다. 같은 부서의 [2026년 청년월세 지원사업 추진계획](https://www.open.go.kr/othicInfo/infoList/infoListDetl.do?prdnNstRgstNo=DCT9BF8233591917F755DF0FFC875049120&prdnDt=20260331144409&nstSeCd=B)은 공개 첨부 PDF 3쪽에서 기존 사업의 계속사업 전환을 언급하고, 4쪽에 사업비 722백만원을 표기합니다.

두 문서의 금액이 다른 이유와 추경 승인 여부는 확인되지 않았습니다. 계획서의 대상 연령도 4쪽의 19~34세와 5쪽의 출생연도 계산 문구가 일치하지 않아 원문 간 차이를 확인해야 합니다. 두 금액이나 대상 조건을 임의로 통합하지 않습니다.

현재 수동 검토 연결 기능의 분류명이 금액 일치로 해석될 여지가 있어 자동 연결에 추가하지 않았습니다. 사업의 연속성과 금액 불일치를 각각 표현하는 방식 및 테스트를 마련한 뒤 연결을 검토합니다. 사업 ID는 `bp-047c3992da1bbbb118dbfea9`입니다. 원문 PDF는 저장소에 포함하지 않습니다.
