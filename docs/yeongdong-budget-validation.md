# 영동군 2026년 일반회계 세출 검증

- 대상: 2026년 본예산 일반회계 세출, 34개 부서·읍면의 사업행 1,305건.
- 확인: 사업행마다 예산액 − 전년도액 = 비교증감, 부서별 사업행 예산 합계와 공식 조직별 세출총괄이 일치합니다. 올해 총액은 510,010,921천원입니다.
- 전년도: 올해 수록된 사업행의 전년도액 합계는 404,913,759천원입니다. 공식 조직별 총괄의 전년도 총액 459,370,768천원과는 범위가 다르므로 기관 전년도 총액으로 사용하지 않습니다.
- 원문 표본: 기획감사과~과수축산과 PDF 86쪽 군민의날 행사(120,000/110,000/10,000천원), 환경과~의회사무과 PDF 202쪽 레이크사랑 걷기대회(20,000/20,000/0천원), 읍면 PDF 1쪽 청사관리운영(89,525/78,960/10,565천원)을 원문 이미지와 대조했습니다. 순서는 올해/전년/증감입니다.
- 자료: [공식 2026년 본예산 목록](https://tour.yd21.go.kr/kr/html/sub03/03020301.html?sch_year=2026&sch_gubun=0&GotoPage=4), 조직별 세출총괄 파일 3136, 사업명세서 파일 3162·3153·3155. 각 사업행에 해당 PDF 주소와 PDF 쪽수를 저장했습니다.
- 사업행 검색과 원문 위치 확인은 `node yeongdong-source-test.cjs`로 검증합니다.
