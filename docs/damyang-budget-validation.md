# 담양군 2026년 일반회계 세출 검증

- 대상: 2026년 본예산 일반회계 기획예산실 1개 부서의 사업행 20건. 담양군 전체 수록이 아닙니다.
- 대조: 공식 PDF에서 추출한 텍스트 기준으로 사업행마다 올해 예산액과 전년도액의 차이가 증감액과 일치합니다. 사업행 예산 합계는 같은 문서의 기획예산실 총액 9,777,227천 원과 일치합니다.
- 검색 표본: 군정 현안 및 주요시책업무 추진 204,600천 원, 전년도 200,100천 원, 증감 4,500천 원. 공식 PDF 1쪽 텍스트 기준입니다.
- 제한: 별도 기관 총괄표와 PDF 이미지 대조는 하지 못했습니다. 점검 당시 군청 원문 파일의 직접 다운로드 및 이미지 조회가 실패해 웹에서 열람한 공식 PDF 텍스트를 사용했습니다. 현재 사업 시행 및 집행 여부는 확인 대상이 아닙니다.
