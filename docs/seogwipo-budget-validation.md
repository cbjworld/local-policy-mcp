# 서귀포시 2026년 일반회계 본예산 대조

- [제주도 공식 본예산 게시물](https://www.jeju.go.kr/finance/budget/2015.htm?act=view&seq=2003239)의 [제3권 PDF](https://www.jeju.go.kr/finance/budget/2015.htm?act=download&seq=2003239&no=4) 734쪽을 대조했습니다. 원본 SHA-256: `d7b2a7e82c2b569deeaf918f339b0e3cd6a71847b654adb15845177a2326d690`.
- 일반회계 조직별 총괄과 일반·특별회계 합산 총괄이 같은 47개 부서의 사업 1,176건을 먼저 선별했습니다. 추가로 나머지 10개 부서에서 일반회계 사업 388건을 확인하고 특별회계 사업 19건을 제외했습니다. 57개 부서의 1,564건 합계는 1,225,221,640천원이며 각 부서의 일반회계 총괄과 일치합니다. 0원 사업 등은 누락될 수 있습니다.
- 원문 텍스트를 독립된 두 PDF 추출 방식으로 대조했고 총괄 58쪽과 명세서 87·497·550쪽의 이미지를 확인했습니다. 497쪽 산후조리비 사업 100,000천원과 550쪽 동부보건소 사업 22,000천원은 서로 다른 원문 행입니다.
- 최소 31개 부서는 올해 수록 사업들의 전년도액 합계와 전년도 부서 총액이 다릅니다. 사업행 합계를 전년도 부서 전체 예산으로 사용하지 않습니다.
- 서귀포시는 제주도 소속 행정시이며 기초자치단체가 아닙니다. 제주도 예산 총액과 서귀포 자료를 중복 합산하지 않습니다. 현재 시행과 집행은 별도 확인 대상입니다.
- 게시물에서 공공누리 표시는 확인하지 못했으며 제주도의 미표시 자료 사전 협의 안내가 사업명·수치 추출에 적용되는 범위는 확인되지 않았습니다. 원문 PDF는 저장소에 포함하지 않고 비공개 개발 자료에만 사용합니다.
- 추가 10개 부서는 일반·특별회계를 단위사업별로 구분하고 회계합산 총괄과 재대조했습니다. 두 PDF 추출 방식으로 사업명·금액 388건을 대조하고 원문 343·439·464쪽 이미지를 확인했습니다. `node seogwipo-source-test.cjs`로 기관 전체 건수, 합계, 원문 위치와 미수록 범위를 검증합니다.
- 57개 부서 명세서 646쪽의 텍스트 레이어에서 세부사업 위치 사업행을 다시 검사했습니다. 일반회계 1,564행은 수록 자료와 사업명·쪽수·금액이 일치했고 특별회계 19행은 구분됐습니다. 예산액 열에서 0·대시·공란 후보는 찾지 못했고 해당 쪽에 이미지 전용 쪽도 없었습니다. 다른 들여쓰기나 벡터 윤곽선으로만 표시된 행은 검사 범위 밖입니다. 재실행 코드는 작업 공간의 `work/seogwipo-zero-wider-audit.py`, 결과는 `outputs/budget-national/seogwipo-zero-wider-audit.json`에 보관했습니다.
