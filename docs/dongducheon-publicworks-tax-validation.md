# 동두천시 공공사업과·세무과 2026년 본예산 대조

[동두천시 본예산 공식 목차](https://www.ddc.go.kr/ddc/contents.do?key=2328)의 일반회계 세출 명세서를 확인했습니다. 사업행마다 문서 주소와 PDF 쪽수를 저장했습니다.

- [공공사업과 원문](https://www.ddc.go.kr/site/ddc/download/file_2026/7-6-1.%EA%B3%B5%EA%B3%B5%EC%82%AC%EC%97%85%EA%B3%BC.pdf) 3쪽의 사업 7건을 이미지로 대조했습니다. 올해 합계 24,800,000천원은 부서 총액과 일치합니다. 올해 수록 사업의 전년도액 합계 13,728,150천원과 원문 부서 전년도 총액 22,212,268천원의 차이 8,484,118천원은 원인을 확인하지 못했습니다. 원문 SHA-256: `4a12893d390f84492abf4f632d675620a4953f8ed330d0a6c9ab41b8b1295cfb`.
- [세무과 원문](https://www.ddc.go.kr/site/ddc/download/file_2026/4-2.%EC%84%B8%EB%AC%B4%EA%B3%BC.pdf) 5쪽의 사업 7건을 이미지로 대조했습니다. 올해 사업행 합계 612,379천원과 전년도 사업행 합계 531,600천원은 각각 원문 부서 총액과 일치합니다. 원문 SHA-256: `b3f7752881304ef20b2c18746dabbe251d861519b02280766cd4d5a211f34204`.
- 두 부서 모두 사업별 올해·전년도 예산과 증감액의 산술 관계를 확인했습니다. 2026년 예산액 열을 전 페이지 이미지로 독립 재검토한 결과, 두 부서의 세부사업 14건이 수록 자료와 대응하며 0원·대시·공란인 세부사업 행은 발견하지 못했습니다. 이 검토는 두 부서에만 해당합니다.
