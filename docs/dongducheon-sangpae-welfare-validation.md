# 동두천 상패동·복지정책과 2026년 일반회계 예산 대조

- [상패동 예산서](https://www.ddc.go.kr/site/ddc/download/file_2026/10-8.%EC%83%81%ED%8C%A8%EB%8F%99.pdf) 1~3쪽의 세부사업 7건은 올해 합계 349,332천원으로 부서 총액과 일치합니다. 모든 행의 예산액과 전년도액 차이는 증감액과 일치합니다.
- 상패동의 올해 수록 사업에 표시된 전년도액 합계는 304,052천원이고 2025년 부서 총액은 323,586천원입니다. [2025년 예산서](https://www.ddc.go.kr/site/ddc/download/file_2025/10-8.%EC%83%81%ED%8C%A8%EB%8F%99.pdf) 2쪽의 주민참여예산 벽화 조성 19,534천원이 2026년 명세서에는 별도 사업행으로 나타나지 않습니다. 사업 폐지 또는 시행 여부는 확인하지 않았습니다.
- [복지정책과 예산서](https://www.ddc.go.kr/site/ddc/download/file_2026/5-1-1.%EB%B3%B5%EC%A7%80%EC%A0%95%EC%B1%85%EA%B3%BC.pdf) 31쪽 중 1~8쪽의 22건만 수록했습니다. 이 사업행 합계는 47,692,493천원이며 부서 총액 58,238,234천원과 다릅니다. 나머지 23쪽은 확인 범위 밖입니다.
- PDF 6쪽의 청년월세 지원사업 306,948천원과 전세보증금 반환보증 보증료 13,000천원, 7쪽 주거취약계층 이사비 10,000천원을 원문 이미지와 대조했습니다. 모든 행의 증감 산술을 확인했으며 현재 시행 여부는 별도 확인 대상입니다.
- 동두천은 8개 동과 복지정책과 일부 페이지만 수록했습니다. 동두천시 전체 부서나 복지정책과 전체 예산은 아닙니다. PDF 원문은 저장소에 포함하지 않았습니다.
