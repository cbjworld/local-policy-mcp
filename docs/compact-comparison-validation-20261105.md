# 여러 지역 비교표 보존 — 2026-11-05

응답 용량을 줄이는 과정에서 일부 기관 대표 출처가 생략되면 응답에 여유가 있어도 비교표를 첫 사례 하나로 줄이던 조건을 수정했다. 24,000자 이내라면 원문을 읽은 비교 사례를 유지하고 남은 공간에 기관별 대표 링크를 가능한 만큼 담는다. 출처 목록을 줄였을 때는 생략 수를 계속 알린다.

실제 `청년 이사비 찾아줘` 조사에서 보관한 로컬 MCP 전체 응답을 변경 전후로 재생했다. 대구 남구와 옥천군의 두 사례 비교 항목이 기존 1개에서 2개로 유지됐고, 응답 크기는 23,887자에서 23,922자였다. 29개 생산기관 이름은 유지됐으며 응답 크기 제한 때문에 대표 링크 생략은 16개에서 25개로 늘었다. 이는 동일한 한 번의 조사 결과를 다시 압축한 시험이며 신규 실시간 검색이나 실제 사업의 완전성을 검증한 것은 아니다. 시험의 출처 보관은 임시 모드였으므로 재시작 후 영구 보존으로 간주하지 않는다.

합성 대량 후보와 두 원문을 이용한 회귀 시험에서 24,000자 제한과 두 비교 사례 보존을 확인했고 전체 자동 검증을 실행했다. 공개 운영 서버에는 반영하지 않는다.
