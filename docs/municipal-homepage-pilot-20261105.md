# 지자체 홈페이지 사업자료 수집 시작

기존 기관 주소록에는 249개 항목이 있으며, 편성 당시 기관명 등 별칭이 포함되어 있어 지자체 수와 같지 않다. 이 중 20개 항목의 등록 주소가 `.go.kr`이 아니었다. 기존 원문 읽기는 해당 주소를 거부하고 있었으므로, 주소록에 등록된 HTTPS 호스트에 한해 허용했다. 임의의 다른 호스트와 사설 IP, 인증서 오류는 계속 차단한다. HTTPS 이동도 매번 주소를 검증한다.

## 실제 원문 시범

- 기관: 서울특별시 노원구
- 문서: 1인가구지원사업 안내
- 원문 위치: https://www.nowon.kr/www/info/info2/info2_09/info2_09_01.jsp
- 2026-11-05 조회: HTML 텍스트 15,634자와 공식 링크 60개 추출. 시스템 신뢰 인증서 사용.
- 내용의 예: 청년일삶센터 운영(19~39세 청년 대상), 자립준비청년 자립지원과 교통비 지원 등 여러 사업을 한 페이지에 안내한다. 각 사업의 기준연도는 페이지 항목별로 확인해야 한다.

이 페이지는 읽기 경로를 시험한 사례이며 전국 수집 목록이나 각 사업의 구조화·검증 완료를 뜻하지 않는다. 주소록은 출발점으로 사용하고, 각 지자체 공고·사업 안내의 발견 범위, 원문 링크, 작성·변경일, 이용 조건, 갱신 상태와 실패 원인을 따로 기록해야 한다.
