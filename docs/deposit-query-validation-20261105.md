# 전세보증료 짧은 질문 검색 — 2026-11-05

`청년 전세보증료 지원 찾아줘`에서 원래 표현 외에 정식 명칭 `전세보증금 반환보증 보증료`와 `청년 보증료 지원`을 함께 검색한다. 지역 지정은 기존 지역 필터로 유지한다. 청년이라는 말이 없는 넓은 검색 결과는 청년 대상이 확인된 것으로 처리하지 않으며 본문 확인 전 대상 미확인으로 유지한다. 사용자가 직접 검색어를 지정한 경우 자동 확장을 덮어쓰지 않는다.

로컬 MCP에서 2026-01-01~2026-10-31, OCR 제외로 변경 전후 각각 1회 조회했다. 변경 전 1.881초, 9쪽에서 34개 문서를 중복 제거했지만 사업 후보와 읽은 문서가 없었다. 변경 후 24.224초, 63쪽에서 문서 569건을 중복 제거하고 후보 299건 중 6건을 읽으려 시도해 2건에서 텍스트를 추출했다. 전체 범위 일부는 이어보기로 남았다. 후보 수와 문서 수는 지자체나 독립 사업 수가 아니다. 두 실행 사이 포털 상황이 달라 재현성과 속도 차이를 일반화하지 않는다.

[영동군 2026년 전세보증금 반환보증 보증료 지원사업 추진 계획](https://www.open.go.kr/othicInfo/infoList/infoListDetl.do?prdnNstRgstNo=DCT33741CA7E774FF086E552E6EBAAC2DA7&prdnDt=20260210180423&nstSeCd=B)의 2쪽에서 사업비 1,200천원, 같은 쪽에서 보증 가입 시기에 따른 최대 40만원 또는 30만원의 지원 한도를 읽었다. 3쪽에는 청년과 청년 외 등의 소득 조건이 각각 기재되어 있다. 일반 검색 결과의 청년 해당 여부는 각 사업 원문에서 별도 확인한다. 작성된 계획을 현재 시행·집행으로 단정하지 않는다.

검색어 세 개와 기존 사용자 지정 검색어 유지, 대상 정보가 없는 제목을 청년 확인으로 표시하지 않는 동작을 자동 시험했다. 이 실측은 영동군 한 문서에서 주요 항목을 찾았는지 확인한 것이며, 전국의 모든 지자체 사업이나 전체 항목의 정확도를 입증하지 않는다.
