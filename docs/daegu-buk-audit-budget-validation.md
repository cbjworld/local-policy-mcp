# 대구 북구 2026년 감사실 예산 검증

- 2026년 본예산 일반회계 감사실 세부사업 7건을 [공식 예산서](https://www.buk.daegu.kr/cmsh/buk.daegu.kr/file/budget_2026_1/6.pdf) 1~4쪽 이미지와 대조했습니다.
- PDF는 일반·기타특별회계 합본입니다. 일반회계 조직별 세출 총괄과 특별회계 단위사업 총괄을 대조해 감사실의 7건을 일반회계로 분리했습니다.
- 사업행의 올해 합계 287,481천원과 전년도 합계 310,115천원은 부서 총액과 일치하며, 모든 행의 금액 차이는 증감액과 일치합니다.
- 북구는 감사실과 의회사무국 두 부서만 수록했습니다. 나머지 부서와 0원 사업은 확인 범위에 포함되지 않습니다.
- [공식 예산 목록](https://www.buk.daegu.kr/index.do?menu_id=00000129)에는 공공누리 표시가 보이지 않았습니다. [구 저작권 안내](https://www.buk.daegu.kr/index.do?menu_id=00001823)가 사업명과 수치의 사실 추출에 적용되는지는 별도로 확인하지 않았으며 PDF 원문 자체는 배포하지 않습니다.
