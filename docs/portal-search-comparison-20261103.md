2026년 11월 3일 정보공개포털 정보목록 화면과 현재 이 작업에 연결된 MCP의 `search_open_documents`를 대조했습니다. 두 검색 모두 검색어 ‘청년월세’, 기간 2026-10-05~2026-11-03, 광역·기초자치단체, 공개 여부 전체, 1쪽·10건을 사용했습니다.

직접 검색은 사람이 수행한 시간으로 측정하지 않았으며, 전체 페이지의 누락률이나 예산·원문 읽기 정확도, AI 답변 생성 시간을 비교한 시험도 아닙니다. 도구 호출에 걸린 한 번의 시간으로 직접 검색 대비 시간 절감률을 계산하지 않습니다. 이 대조는 연결된 기존 MCP의 검색 도구를 사용했으므로 비공개 개발본 전체의 검색 품질 검증과 구분합니다.
