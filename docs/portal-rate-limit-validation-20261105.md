# 정보공개포털 요청 제한 대응 검증

2026-11-05 실제 업무 질문 `반려동물 의료비 지원 찾아줘`를 2026년 1월 1일~10월 31일 범위로 조회했다. 조회는 18.681초 걸렸고 87쪽을 읽은 후 두 검색 표현의 전체 공개 범위에서 각각 42쪽과 45쪽에 포털 응답 코드 429가 발생했다. 468건의 중복 제거 문서는 검색 결과 문서 수이며 사업 수가 아니다. 7개 첨부를 읽으려 했지만 텍스트를 추출한 문서는 없었다. 검색은 미완료다.

기존에는 요청 제한을 받은 쪽을 같은 요청 안에서 곧바로 다시 시도했다. 변경 후에는 429를 확인하면 진행 중인 요청의 응답은 받아들이되 새 검색을 중단한다. 실패한 쪽과 시작하지 못한 범위는 후속 검색 목록에 남긴다. 일반적인 일시 오류는 계속 기존 방식대로 재시도한다. 제한 해제 시각은 포털에서 확인되지 않았으며, 재개가 자동으로 완료됐다고 판단하지 않는다.

자동 테스트는 포털의 429를 재현하여 즉시 재시도가 없는지, 실패 쪽이 남는지 확인한다. 실제 429 사례는 변경 전 관측이며 수정된 버전의 실제 포털 재현 시험은 추가 호출을 피하기 위해 수행하지 않았다.
