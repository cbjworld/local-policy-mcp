# 수행 기관이 다른 문서 구분 — 2026-11-05

같은 기관·부서·연도와 비슷한 제목으로 묶인 문서에서도 본문에서 확인된 도서관명이나 지자체(교육청)명이 서로 다르면, 해당 묶음의 문서를 개별 분리해 대상·예산 인용을 섞지 않는다. 해당 정보가 같은 경우 기존 묶음 방식을 유지한다. 이름 차이가 있을 때만 보수적으로 분리하며, 이름이 없다는 것은 사업이 같다는 증거가 아니다.

자동 시험에서 제목이 같은 계열인 서로 다른 두 도서관 문서의 예산 근거가 분리되고, 도서관명이 같은 경우 기존 그룹이 유지됨을 확인했다. 기관명 차이는 합성 시험 데이터이며 실제 문서에서 발견한 사례라고 주장하지 않는다. 기존 부산 광역·기초 사업 연결 및 광명의 다중 사업 문서 회귀 검증을 포함한 전체 자동 시험이 통과했다. 선택적 Poppler 검사는 실행하지 않았다.

실제 로컬 MCP에서 `청년 면접비 찾아줘`, 2026-01-01~2026-10-31, OCR 제외 1회를 실행했다. 42.561초 동안 6건을 열어 2건에서 텍스트를 읽었고 영도구·기장군 문서 후보가 각각 반환됐다. 면접수당 전체 범위 20쪽에서 연결 시간이 초과돼 이어보기로 표시됐다. 이번 실제 질문은 도서관명이 다른 문서를 포함하지 않으므로 새 분리 동작을 실제 문서로 입증하지는 않는다. 소요시간에는 원문 연결 대기가 포함되고 AI 답변 생성·원격 서버 기동은 포함하지 않는다.
