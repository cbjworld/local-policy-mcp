# 동두천시 2026년 일반회계 세출 검증

- 대상: 본예산 일반회계 생연1동 세부사업 7건. 시 전체 예산이 아닌 한 개 동의 자료입니다.
- [공식 예산 목록](https://www.ddc.go.kr/ddc/contents.do?key=2328)과 [생연1동 명세서 PDF](https://www.ddc.go.kr/site/ddc/download/file_2026/10-1.%EC%83%9D%EC%97%B01%EB%8F%99.pdf)의 이미지 1~2쪽을 대조했습니다.
- 사업행의 올해 합계 334,130천원과 전년도 합계 353,010천원은 PDF의 부서 총액과 각각 일치합니다. 모든 사업행의 올해 금액과 전년 금액의 차이는 증감액과 일치합니다.
- 명세서와 목록에는 공공누리 표시가 보이지 않았으며, 원문을 수록하지 않고 사업명·예산액과 원문 위치만 보관했습니다. [시 저작권정책](https://www.ddc.go.kr/ddc/contents.do?key=1372)의 안내가 이 사실정보 추출에 적용되는지 별도 확인하지 못했습니다.
- 검색, 부분 수록 표시, 합계, 원문 연결은 `node dongducheon-source-test.cjs`로 점검합니다.
