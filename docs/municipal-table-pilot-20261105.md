# 지자체 홈페이지 사업별 표 분리 시범

노원구 [1인가구지원사업 안내](https://www.nowon.kr/www/info/info2/info2_09/info2_09_01.jsp)를 2026-11-05에 직접 내려받아 명시적으로 `사업명`과 `사업내용` 열이 있는 표의 행을 분리했다. 5개 표에서 후보 31개가 나왔으며, 별도 HTML 파서로 원문 각 행의 사업명과 내용을 대조한 결과 31개 모두 공백을 제외하고 일치했다.

로컬 추출 파일에는 사업명·본문·담당부서·원문 URL·표 번호·행 번호·원본 SHA-256을 기록한다. 대상·금액·연도·현재 시행 여부를 자동으로 확정하지 않으며, 다른 출처와 같은 사업인지도 아직 연결하지 않는다. 병합 셀이나 중첩 표는 결과에서 제외하고 미처리 사유를 남긴다. 현재 UTF-8 문서만 처리하며, 다른 인코딩은 오류를 보고한다.

이는 노원구 한 페이지로 검증한 초기 추출기다. 내려받은 원문과 추출 결과는 이 검증에서 저장소에 포함하지 않았다.

## 로컬 MCP 검색 시범

서버 시작 전 `POLICY_MUNICIPAL_CATALOG`에 추출 JSON의 절대경로를 지정하면 `search_municipal_homepage` 도구가 나타난다. 지정하지 않은 서버는 기존 도구 구성을 유지한다. 검색은 지정된 통합 파일 안에서 이루어지며, 자료는 서버에 함께 배포되지 않는다. UTF-8 JSON 파일에 포함된 원문 주소는 기관 주소록과 대조한다. 사업명과 내용의 모든 검색어가 들어간 행을 반환하며 문서 URL, 원본 해시, 표·행 위치와 자료 범위를 제공한다.

실제 노원구 추출 파일을 설정한 로컬 MCP에 `청년 39세`, `노원구`를 호출해 청년일삶센터와 도전숙 두 행이 원문 위치와 함께 반환되는 것을 확인했다. 본문의 대상 표기는 해당 행의 내용이며, 검색 결과만으로 현재 시행이나 기관 고유 사업임을 확정하지 않는다. 여러 지자체의 게시판 탐색, 이용 조건 확인, 다양한 형식의 파서, 수집 상태 관리와 갱신은 남아 있다.

## 과천시 추가 시범

[과천시 1인가구 지원사업 안내](https://www.gccity.go.kr/dept/contents.do?mId=0212020700)는 사업명이 행 제목(`th scope="row"`)이고 지원내용이 별도 열에 있는 형식이었다. 추출기를 보완해 12개 행을 분리했으며, 독립 파서로 사업명·사업내용·지원내용의 원문 일치를 12/12 확인했다. 신청 링크도 원문에서 보존하되 링크 대상은 별도로 조회·검증하지 않았다.

두 홈페이지의 추출 파일을 하나로 통합한 로컬 MCP에서 `과천시 병원 동행` 검색 결과의 원문 위치·지원내용·링크를 확인했다. 통합 파일은 `sources` 배열에 각 페이지 추출 결과를 담는다. 여전히 2개 페이지만 수록한 시범이며, 지역별 전체 사업 현황을 뜻하지 않는다.
