# 지자체 홈페이지 사업별 표 분리 시범

노원구 [1인가구지원사업 안내](https://www.nowon.kr/www/info/info2/info2_09/info2_09_01.jsp)를 2026-11-05에 직접 내려받아 명시적으로 `사업명`과 `사업내용` 열이 있는 표의 행을 분리했다. 5개 표에서 후보 31개가 나왔으며, 별도 HTML 파서로 원문 각 행의 사업명과 내용을 대조한 결과 31개 모두 공백을 제외하고 일치했다.

로컬 추출 파일에는 사업명·본문·담당부서·원문 URL·표 번호·행 번호·원본 SHA-256을 기록한다. 대상·금액·연도·현재 시행 여부를 자동으로 확정하지 않으며, 다른 출처와 같은 사업인지도 아직 연결하지 않는다. 세로 병합 행과 중첩 표는 결과에서 제외하고 미처리 사유를 남긴다. 가로 병합은 머리글과 행의 폭이 정확히 일치할 때만 처리한다. 현재 UTF-8 문서만 처리하며, 다른 인코딩은 오류를 보고한다.

이는 노원구 한 페이지로 검증한 초기 추출기다. 내려받은 원문과 추출 결과는 이 검증에서 저장소에 포함하지 않았다.

## 로컬 MCP 검색 시범

서버 시작 전 `POLICY_MUNICIPAL_CATALOG`에 추출 JSON의 절대경로를 지정하면 `search_municipal_homepage` 도구가 나타난다. 지정하지 않은 서버는 기존 도구 구성을 유지한다. 검색은 지정된 통합 파일 안에서 이루어지며, 자료는 서버에 함께 배포되지 않는다. UTF-8 JSON 파일에 포함된 원문 주소는 기관 주소록과 대조한다. 사업명과 내용의 모든 검색어가 들어간 행을 반환하며 문서 URL, 원본 해시, 표·행 위치와 자료 범위를 제공한다.

Codex에서 별도 로컬 MCP로 사용하려면 MCP 서버의 실행 명령을 `node --use-system-ca`와 이 저장소의 `mcp.js` 경로로 지정하고, 서버 환경변수 `POLICY_MUNICIPAL_CATALOG`에 통합 자료의 절대경로를 넣는다. 설정을 바꾼 뒤에는 새 세션에서 도구 목록을 확인한다. 통합 파일 경로와 자료는 사용하는 PC에 있어야 한다.

검증한 새 통합 자료를 기존 파일에 반영할 때는 `python municipal-promote.py 기존파일 새파일`을 실행한다. 기존 출처가 하나라도 빠지거나 달라졌거나, 새 출처가 비어 있거나 임시 접속 주소면 교체하지 않는다. 교체 전 백업을 남기며, 기존 출처를 수정하는 갱신은 별도 검토가 필요하다. 이 명령은 자동 수집이나 예약 실행을 설정하지 않는다.

출처 범위는 기본 20개씩 반환하며 `scope.totalSources`가 전체 출처 수다. `scope.nextSourceOffset`이 있으면 다음 호출의 `sourceOffset`에 넣어 나머지 출처를 볼 수 있다. `sourceLimit`은 최대 100이다. 사업 결과의 `offset`과는 별개이며 각 사업에도 원문 링크가 있다.

본문은 기본 2,000자씩 반환한다. 긴 항목은 같은 검색어와 결과 위치를 유지하고 `limit`을 1로 지정한 뒤, 항목의 `nextContentOffset`을 다음 호출의 `contentOffset`에 넣으면 이어 읽을 수 있다. 영등포구 주차장 개방 안내 4,769자를 세 부분으로 재구성해 원문 추출본과 대조했다.

`link_municipal_budget_candidates`는 지자체와 질문을 받아 홈페이지 안내와 예산 사업행을 각 20건씩 대조한다. `websiteOffset`, `budgetOffset`으로 자료 쪽 조합을 선택하고, 같은 조합의 후보가 20건보다 많으면 `nextPairOffset`으로 이어본다. 양주시 실제 예산의 두 번째 쪽에서도 연결 후보가 반환되는지 MCP 호출로 확인했다. 자동으로 전체 쪽을 훑지는 않는다. 같은 지자체의 이름 일치 후보에 두 원문을 함께 표시하며, 예산과 지원 단가를 구분한다. 파주시 노인 난방비와 칠곡군 청년월세에서 후보를 확인했고, 순창군의 노인 보청기 안내와 선천성 난청 예산은 연결하지 않는 것을 확인했다. 이름 일치는 동일 사업의 확정이 아니며 각 자료의 연도·범위를 확인해야 한다.

`link_municipal_budget_auto`는 페이지 조합을 한 번에 최대 20회씩 이어 대조한다. `complete`가 거짓이면 같은 질문과 반환된 `cursor`로 다시 호출해야 하며, 자료가 바뀌면 처음부터 다시 검색한다. 양주시 실제 자료의 예산 35쪽을 네 차례 호출해 수동 대조 결과와 같은 후보 8건을 확인했다. 각 호출 사이 서버를 새로 실행한 경우에도 이어졌다. 서버가 대화 없이 스스로 끝까지 실행하는 백그라운드 작업은 아니다.

지자체를 생략하면 수록된 전국 자료를 대조한다. `청년 월세` 실사에서 사상구·양주시·칠곡군의 후보 3건이 나왔으며, 서버를 매 호출마다 새로 실행해도 이어졌다. 같은 구 이름이라도 상위 지자체가 다르면 연결하지 않는다. 이 범위는 현재 보유한 자료에 한정된다.

대조 완료 응답에는 홈페이지 출처 수와 예산 자료의 연도·수록 범위를 함께 반환한다. 완료는 수록된 자료의 검색 결과를 모두 대조했다는 의미이며 전국 모든 사업을 확인했다는 뜻은 아니다. 실제 로컬 MCP 시험에서 홈페이지 56개 출처와 예산 자료의 전국 미완료 상태가 표시되는지 확인했다.

홈페이지 범위에는 서로 다른 광역·기초 지자체 수와 미처리 항목 수도 표시한다. 실제 자료에서 56개 출처는 33개 지자체이며 미처리 항목 62개가 있었다. 미처리 항목은 표나 구역의 개수로, 누락된 사업 수라고 단정하지 않는다.

한 번의 자동 대조 안에서 같은 자료 쪽을 반복해서 읽지 않도록 개선했다. 양주시 `지원` 질문으로 20개 쪽 조합을 대조한 로컬 세 차례 시험은 변경 전 약 0.76~1.04초, 변경 후 약 0.63~0.87초였다. 양주·칠곡·순창의 자동 대조 후보는 각각 수동으로 쪽을 넘겨 대조한 결과와 일치했다. 실행 환경에 따라 속도는 달라진다.

질문에 지정 지자체가 함께 쓰인 경우(예: `파주시의 노인 난방비`) 그 지역명만 검색 주제에서 분리한다. 다른 지역명이나 사업명 일부는 제거하지 않는다. 파주시와 칠곡군 실제 자료 및 MCP 호출에서 지역명이 포함된 질문을 확인했다.

순창군 [임신지원금 홈페이지](https://www.sunchang.go.kr/index.do?menuUid=ff8080819a2f0e3b019ac93f6a5448dc)와 [2026년 예산서 12쪽](https://www.sunchang.go.kr/resource/www/download/budget/2026/02/02_22.pdf)을 별도로 대조했다. 홈페이지의 임신 1회당 100만원 지원과 예산서의 100만원 × 120명, 예산액 120,000천원은 단가와 총편성액으로 구분된다. 홈페이지는 공공누리 제4유형을 표시하므로 본문 재배포·이용 조건을 지켜야 한다. 칠곡군 예산 원문은 재조회 중 연결 오류가 발생해 이번에는 재대조하지 못했다.

검색 파일은 최대 20MiB, 출처는 최대 5,000개까지 허용한다. 출처가 늘 때 지자체 주소록을 매번 전부 훑지 않도록 호스트별로 미리 묶어 확인하며, 주소가 여러 지자체와 연결되면 계속 검토 대상으로 처리한다.

실제 노원구 추출 파일을 설정한 로컬 MCP에 `청년 39세`, `노원구`를 호출해 청년일삶센터와 도전숙 두 행이 원문 위치와 함께 반환되는 것을 확인했다. 본문의 대상 표기는 해당 행의 내용이며, 검색 결과만으로 현재 시행이나 기관 고유 사업임을 확정하지 않는다. 여러 지자체의 게시판 탐색, 이용 조건 확인, 다양한 형식의 파서, 수집 상태 관리와 갱신은 남아 있다.

## 과천시 추가 시범

[과천시 1인가구 지원사업 안내](https://www.gccity.go.kr/dept/contents.do?mId=0212020700)는 사업명이 행 제목(`th scope="row"`)이고 지원내용이 별도 열에 있는 형식이었다. 추출기를 보완해 12개 행을 분리했으며, 독립 파서로 사업명·사업내용·지원내용의 원문 일치를 12/12 확인했다. 신청 링크도 원문에서 보존하되 링크 대상은 별도로 조회·검증하지 않았다.

두 홈페이지의 추출 파일을 하나로 통합한 로컬 MCP에서 `과천시 병원 동행` 검색 결과의 원문 위치·지원내용·링크를 확인했다. 통합 파일은 `sources` 배열에 각 페이지 추출 결과를 담는다. 여전히 2개 페이지만 수록한 시범이며, 지역별 전체 사업 현황을 뜻하지 않는다.

## 성동구 추가 시범

[성동구 1인가구 지원사업 안내](https://www.sd.go.kr/main/contents.do?key=4778)를 직접 내려받아 4개 표의 사업 후보 36행을 추출했다. 별도 HTML 파서로 모든 열을 비교해 36/36행이 원문과 일치했다. 노원구·과천시와 합친 3개 페이지, 79행의 로컬 자료로 MCP를 호출하여 `병원 동행`, `1인가구 안전` 검색과 원문 위치 반환을 확인했다. 추출 시각은 원문의 작성일이나 자료 수집 시각이 아니므로 별도 표시한다. 원문과 통합 데이터는 로컬에만 저장했다.

## 사하구·영월군 추가 시범

[사하구 중장년 1인가구 지원](https://www.saha.go.kr/portal/contents.do?mId=0509020300) 6행과 [영월군 청소년·교육지원](https://www.yw.go.kr/www/contents.do?key=1213) 10행을 수집해 별도 파서로 모든 열이 각각 6/6, 10/10 원문과 일치함을 확인했다. 영월군은 `사업내용` 대신 `지원내용` 열을 사용하므로 추출기가 해당 열 이름을 보존하도록 확장했다. 5개 페이지 95행을 담은 로컬 MCP에 `영월군 장학`을 질의하여 3행과 원문 위치를 확인했다.

[해운대구 청년 지원](https://www.haeundae.go.kr/index.do?menuCd=DOM_000000103001005006)은 가로 병합 셀의 배열이 머리글과 일치하는 9행을 추출해 원문의 모든 열과 9/9 일치함을 확인했다. 세로 병합이 있는 5행은 미처리로 남겼다. 6개 페이지 104행을 담은 로컬 MCP에서 `해운대구 전세 보증료`를 검색해 원문 위치와 미처리 5행 표시를 확인했다. 각 페이지는 해당 지역의 모든 사업을 나타내지 않는다.

## 인제군·남양주시·영월군 추가 페이지

- [인제군 청년지원정책](https://www.inje.go.kr/portal/field-info/youth): 추출 23행의 모든 열이 원문과 일치했고, 3개 항목은 미처리로 남았다.
- [남양주시 사회복지 종사자 처우개선](https://www.nyj.go.kr/www/contents.do?key=4938): 추출 3행의 모든 열이 원문과 일치했고, 11개 항목은 미처리로 남았다. 최초 페이지는 이 주소로 화면 이동을 안내했다.
- [영월군 일자리 지원](https://www.yw.go.kr/www/contents.do?key=1215): 추출 3행의 모든 열이 원문과 일치했다.

총 9개 페이지의 133행을 로컬 MCP 검색 자료로 합쳤다. `인제군 청년 일자리`와 `남양주시 복지포인트`의 검색 결과를 실제 MCP 호출로 확인했다. 수록 페이지 전반에 미처리 항목 19개가 남아 있으며, 이는 행이나 표가 섞인 수치다. 홈페이지·분야별 전체 사업을 확인했다는 의미는 아니다.

### 정정: 인제군 표 중간 열 제목 변경

인제군의 주거 관련 표 중간에 열 제목이 바뀌는데도 초기 추출기는 첫 번째 제목을 계속 사용했다. 그 결과 6행에서 사업 위치가 지원내용으로, 사업내용이 지원조건으로 잘못 표시됐다. 위의 최초 대조는 행에 가장 가까운 제목이 아니라 첫 번째 제목을 기준으로 비교했으므로 이 오류를 발견하지 못했다. 사업의 존재를 새로 확인한 것이 아니라 열을 잘못 연결한 오류다.

추출기를 수정해 중간 제목을 적용하고 9개 페이지 133행을 가장 가까운 제목 기준으로 다시 대조했다. 133/133행이 해당 원문 열과 일치했고, 제목 행은 미처리 항목으로 세지 않아 미처리는 18개가 되었다. 로컬 MCP의 `인제군 지역활력타운` 검색에서 사업위치와 사업내용이 올바른 열로 나오는 것도 확인했다. 이전 추출 파일은 새로 생성한 파일로 교체했다.

## 로컬 자료 통합 보호

`municipal-catalog-merge.py`는 개별 추출 파일을 기존 통합 자료와 합친다. 등록된 공식 홈페이지 주소·원문 해시·행 위치를 점검하고, 읽지 못한 자료나 행 수가 기존의 절반 미만으로 줄어든 자료는 이전 것을 유지한 채 검토 대상으로 남긴다. 이 절반 기준은 누락 여부를 판정하는 기준이 아니라 급격한 감소를 감지하는 안전장치다. 같은 원문 해시라도 추출 결과가 달라지면 수정 내용을 반영한다. 파일 교체는 임시 파일에 기록한 뒤 수행한다.

실제 6개 페이지 자료에 정정된 추출 결과와 3개 추가 페이지를 합쳐, 독립적으로 만든 9개 페이지 133행의 자료와 추출 시각을 제외한 내용이 일치하는지 확인했다. 통합한 파일을 로컬 MCP에 연결해 인제군 사업내용과 위치도 확인했다. 이 도구는 수집이나 자동 실행 자체를 수행하지 않는다.

`municipal-batch-extract.py`는 로컬에 이미 내려받은 원문 목록을 받아 표·사업 안내 추출과 기존 자료 통합을 일괄 수행하고, 성공·실패·검토 대상을 보고한다. 읽기 실패나 추출 행 급감 시 기존 자료를 보존하고, 원문·목록 파일은 결과로 덮어쓰지 않는다. 기존 16개 원문을 대상으로 16개 처리, 실패 0, 기존 364행 유지, 미처리 60항목을 확인했다. 추출기 개선으로 9개 페이지가 갱신됐으나, 원문·행 내용은 기존 검증 자료와 같았다. 자동 다운로드·새 홈페이지 탐색·정기 실행은 아직 연결하지 않았다.

## 기존 목록의 재다운로드 시범

`municipal-stage-download.cjs`는 이미 확보한 공식 주소 목록을 일정량씩 읽고, 등록된 기관 호스트·`robots.txt` 허용 여부와 수집 간격을 확인한 뒤 원문을 별도 임시 보관한다. 다른 호스트로의 자동 이동은 허용하지 않는다. 수집 실패는 보고서에 남기고 기존 원문을 덮어쓰지 않는다. 다음 목록 위치도 기록한다. 새 홈페이지를 자동 발견하거나 정기 실행하는 기능은 아니다.

2026-11-05 실제 4개 주소를 시험해 노원구·사하구 2개 페이지를 수집했고 성동구는 `robots.txt`에 따라 수집을 중단했으며 과천시는 연결이 끊겼다. 새 원문 두 페이지를 일괄 추출·통합했을 때 전체 16페이지 364행이 유지됐고, 검색도 정상 동작했다. 사하구 원문 해시는 달라졌으나 추출된 사업 내용은 기존과 같았다. 수집 제한·실패는 자료가 없다는 뜻이 아니다.

같은 날 기존 16개 주소 전체에 대해 이 절차를 이어서 실행했다. 9개는 재수집, 6개는 각 사이트 수집 규칙으로 중단, 1개는 연결 오류였다. 9개 재수집 페이지는 일괄 추출·통합했으며, 원문 해시가 달라진 페이지도 추출 사업 내용은 기존과 일치했다. 차단·오류 페이지는 기존 자료를 유지해 16페이지 364행과 미처리 60항목이 남았다. 실제 로컬 MCP에서 의왕시 청년 주거, 사상구 청년 일자리, 해운대구 난임 검색을 확인했다. 이는 기존에 확인한 주소의 재점검이며 전국 홈페이지 자동 발견이나 전체 수집이 아니다.

## 공식 메뉴 후보 발견 시범

`municipal-discovery.cjs`는 등록된 홈페이지의 첫 페이지를 수집 규칙에 따라 확인하고, 같은 호스트의 사업 관련 메뉴 링크를 미검증 후보로 반환한다. 첫 페이지의 최대 1,000개 링크만 살피므로 누락될 수 있으며, 외부 사이트·다운로드 파일은 탐색 후보에서 제외한다. 이후 각 후보를 읽기 전에 수집 규칙을 다시 확인한다.

노원구·사하구·해운대구 첫 화면에서 각각 24개·29개·0개 메뉴 후보를 발견했다. 후보 중 노원구 [다자녀가구 지원사업](https://www.nowon.kr/www/info/info2/info2_05/info2_05_05/info2_05_05_01.jsp)의 표 17행을 분리해 원문과 대조하고 로컬 MCP에서 `노원구 다자녀` 검색을 확인했다. 사하구 자립준비청년 안내는 현재 표 추출기로 사업 행이 나오지 않아 검토 대상으로 남겼다. 통합 자료는 17페이지 381행이며, 발견한 메뉴 수와 사업 수는 다르다.

## 지자체 명단 순차 탐색

`municipal-discovery-batch.cjs`는 기관 주소록에서 편성 당시 별칭을 뺀 245개 주소를 순서대로 탐색한다. 페이지마다 결과와 실패 사유를 로컬 상태 파일에 저장하여 중단 후 미처리 주소부터 이어 간다. 사이트 수집 규칙으로 차단된 경우 원문을 가져오지 않는다. 최초 12개 주소를 점검한 후 다음 4개 주소를 처리하여 실제 재개가 되는 것을 확인했다. 전국 탐색은 진행 중이며, 결과는 검증 전 메뉴 후보로만 보관한다. 기존 실패 항목의 자동 재시도와 메뉴 후보 본문 수집은 별도 단계다.

[파주시 저소득 노인 지원](https://www.paju.go.kr/www/www_02/www_02_01/www_02_01_02/www_02_01_02_02/www_02_01_02_02_01.jsp)의 사업별 세로 표 3개도 제목과 표 내용을 대조했다. 난방비 및 개안수술 검색을 확인하고 기존 출처가 보존되는지 점검했다.

세로 표는 설명 문구에 단어가 있는 것만으로 사업으로 처리하지 않고, 실제 표에서 대상과 내용·금액 항목에 값이 있는지 확인한다. 장흥군과 파주시 표를 다시 추출해 기존 사업 항목이 유지되는지 대조했다.

## 의왕시·사상구·해운대구 추가 페이지

- [의왕시 생애주기별 인구정책](https://www.uiwang.go.kr/UWKORWEL1901): 150행의 각 열을 원문과 대조했다. 같은 사업명이 반복되는 행이 있으므로 독립 사업 수로 세지 않는다.
- [부산 사상구 청년·일자리](https://www.sasang.go.kr/index.sasang?menuCd=DOM_000000103008003005): 7행을 원문과 대조했다. `사업명 / 서비스명`, `사업내용 / 지원내용` 제목을 추출기가 인식하도록 확장했다.
- [해운대구 육아 지원](https://www.haeundae.go.kr/index.do?menuCd=DOM_000000103001005003): 안전하게 분리한 18행의 각 열을 원문과 대조했고, 세로 병합으로 이어지는 30행은 미처리로 남겼다. 병합 영역 안의 소표 제목은 전체 표 제목이 아니다.

기존 자료와 합쳐 12개 페이지 308행, 미처리 48항목을 로컬에 보관한다. MCP에서 `사상구 취업`, `해운대구 아이돌봄` 검색을 확인했다. `청년 주거`와 `청년 일자리`는 단어가 같은 행에 모두 없으면 결과가 빠지는 문제가 확인되어 검색 개선이 필요하다. 단순 키워드 일치는 사업의 의미상 관련성이나 독립성을 검증하지 않는다.

`청년 일자리`와 같이 연령 대상어와 사업 주제를 함께 입력하고 완전 일치가 없으면, 사업명에 주제어가 있고 대상이 기재되지 않은 행을 `target_unconfirmed` 후보로 표시하도록 개선했다. 상충하는 연령이 명시된 행은 후보에서 제외한다. 로컬 MCP에서 `사상구 청년 일자리`는 일자리센터와 박람회 두 건을 청년 대상 미확인 후보로 반환했고 기존 `사상구 취업`의 5건은 유지됐다. `의왕시 청년 주거`는 여전히 결과가 없으며, 유의어·페이지 맥락 활용은 아직 지원하지 않는다. 후보 표시는 해당 대상을 확정하거나 현재 시행을 확인한 것이 아니다.

### 의왕시 청년복지 원문 추가

기존 의왕시 생애주기별 표에 주거 사업이 없었으나, 별도의 [청년복지 안내](https://www.uiwang.go.kr/UWKORWEL1604)에 사업별 제목과 내용이 있었다. 표가 아닌 명시적 사업 제목과 안내 영역을 분리하는 추출기를 추가했고, 별도 HTML 파서로 추출한 5개 사업의 제목과 안내 전체를 대조해 5/5 일치했다. 안내 조건이 부족한 1개 항목은 미처리로 남겼다.

13개 페이지의 313개 사업 후보를 로컬 MCP에서 검색한 결과, `의왕시 청년 주거`에 `청년월세 한시 특별지원(2차)`과 `청년 이사비 지원사업`이 각각 원문 URL과 구역 번호를 포함해 반환됐다. 월세 안내의 신청기간은 2024-02-26~2025-02-25로, 이 결과만으로 현재 모집을 판단하지 않는다. 이 방식은 현재 확인한 홈페이지의 명시적 구조에 한하며 다른 사이트의 모든 문서 형식을 처리하지 않는다.

추가 대조에서 미처리됐던 의왕시 청년 취업활동 지원금은 `지원내용` 대신 `지원조건`에 내용을 적은 안내였다. 해당 표현을 그대로 보존하면서 수집하도록 보완해 6개 안내 전부를 원문과 대조했다. `의왕시 청년 취업활동` MCP 검색에 원문과 구역 번호가 반환되는 것을 확인했다.

## 홍천군·해운대구 추가 안내

[홍천군 1인가구 지원](https://www.hongcheon.go.kr/www/contents.do?key=2702) 6행, 해운대구 [임산부 지원](https://www.haeundae.go.kr/index.do?menuCd=DOM_000000103001005000) 21행과 [노인 지원](https://www.haeundae.go.kr/index.do?menuCd=DOM_000000103001005005) 23행을 추출해 각 열을 원문과 대조했다. 해운대구의 세로 병합 행은 두 페이지에서 각각 6행씩 미처리다. 16개 페이지 364개 후보를 담은 로컬 MCP에서 `홍천군 독거노인`, `해운대구 난임`, `의왕시 청년 취업활동` 검색을 확인했다. 미처리 항목은 총 60개이며 페이지 내 표·행 수이고 사업 수가 아니다.

### 병합 행 추가 점검

보관된 [해운대구 청년 지원 페이지](https://www.haeundae.go.kr/index.do?menuCd=DOM_000000103001005006)의 청년내일저축계좌는 사업명과 담당부서에 `rowspan=6`이 지정됐지만 실제 표의 해당 구간에는 다섯 행만 있다. 단순히 병합 길이대로 행을 합치는 실험은 이 자료를 안전하게 복원하지 못해 반영하지 않았다. 실험 당시에는 미처리 표시를 유지했다.

이후 현재 로컬 목록에 기록된 SHA-256과 일치하는 보관 원문을 찾아 표 1의 11~15행을 직접 대조했다. 표 마지막 사업의 다섯 행을 한 건으로 수동 복원해 해당 로컬 목록에 추가했으며, 원문 위치와 수집 당시 조건을 함께 유지했다. `청년내일저축계좌`, `해운대구`로 연결된 로컬 MCP에서 한 건을 확인했다. 이는 해당 원문 한 건을 확인한 결과이고, 다른 병합 표의 자동 처리를 뜻하지 않는다.

남양주시 사회복지종사자 처우개선 안내의 표 2는 분야 열만 여러 행에 걸치고 각 행에 독립된 사업명·지원내용이 있다. 이 형태에 한해 추출기가 각 행을 분리하도록 개선했다. 목록에 기록된 해시와 같은 보관 원문에서 11개 행을 각각 대조하고 로컬 목록에 추가했으며, 기존 3개 항목은 그대로 유지했다. 원문 페이지가 사회복지종사자 처우개선 안내라는 범위도 각 항목에 남겼다. 연결된 로컬 MCP에서 남양주시 `유급병가` 검색으로 사업명·내용·원문 위치·페이지 범위를 확인했다. 세부 대상과 적용 여부는 원문 기준으로 확인한다.

인제군 청년 안내 표 3의 지역 인재육성 장학사업은 사업명과 신청시기·문의처가 두 행에 걸쳐 있고, 둘째 행에 신청대상이 이어진다. 로컬 목록의 해시와 일치하는 보관 원문 3~4행을 직접 대조해 한 사업으로 복원하고, 장학금 내용과 신청조건·문의처를 분리해 유지했다. 연결된 로컬 MCP에서 인제군 `인재육성` 검색으로 원문 위치와 내용을 확인했다.

해운대구 육아 안내의 가정양육수당은 표 1의 2~6행에 지원대상과 연령별 금액이 나뉜다. 로컬 목록의 해시와 같은 보관 원문을 직접 대조해 한 건으로 복원하고, 일반 양육수당과 장애아동 양육수당의 열 제목·연령·금액을 원문 순서로 보존했다. 연결된 로컬 MCP에서 `가정양육수당`, `해운대구`로 내용을 확인했다. 이는 보관된 안내 기준이며 다른 병합 사업의 복원을 뜻하지 않는다.

같은 표의 부모급여 7~13행도 보관 원문과 대조해 한 건으로 복원했다. 어린이집 이용 여부별로 병합된 항목을 각 연령 행에 표시하고 현금·보육료를 구분해 유지했다. 지원대상의 `만 2세 미만`과 표의 `12 ~ 24개월` 표기가 달라 두 표현을 모두 보존하고 적용 연령 대조 안내를 남겼다. 연결된 로컬 MCP에서 `부모급여`, `해운대구`로 검색을 확인했다.

같은 표의 청소년부모 아동양육비 지원 17~20행은 한 사업의 지원대상, 가구원 수별 소득기준, 자녀 1인당 지원액과 신청방법이다. 목록과 해시가 일치하는 보관 원문을 대조해 한 건으로 복원하고 열 제목과 금액을 함께 유지했다. 연결된 로컬 MCP에서 `청소년부모 아동양육비`, `해운대구`로 검색을 확인했다.

해운대구 홈페이지와 2026 일반회계 예산을 대조할 때 `부모급여`는 이름이 짧아 후보에서 빠졌다. 같은 지자체에서 접미어를 제외한 이름이 네 글자 이상이고 정확히 같으면 후보가 되도록 보완했다. [해운대구 예산서 원문](https://www.haeundae.go.kr/board/download.do?boardId=BBS_0000048&paging=ok&startPage=1&dataSid=3157148&command=update&fileSid=3122637)을 직접 내려받아 PDF 238쪽의 부모급여·가정양육수당과 235쪽의 청소년부모 아동양육비 사업명 및 편성액을 각각 대조했다. 세 건 모두 홈페이지와 예산의 연결 후보로 반환되며, 편성액은 개인별 지원액과 구분한다. 이름과 지자체 일치만으로 사업 범위나 연도까지 확정하지 않는다.

홈페이지·예산 연결 후보에 이름 일치 수준을 추가했다. 실제 `출산 지원` 대조에서 해운대구의 `신혼부부 출산장려용품 지원`과 `출산장려용품지원`은 이름 일부 일치, `청소년산모 임신·출산의료비 지원`은 표기 정규화 후 일치로 구분된다. `부모급여`와 `부모급여 지원`은 접미어 차이로 구분된다. 특히 일부 일치는 대상과 범위를 원문에서 대조하기 전 같은 사업으로 확정하지 않는다.

지자체를 별도 입력하지 않고 질문에 `해운대구 부모급여`, `인제군의 인재육성`처럼 적는 경우, 전국 지자체 주소록에서 이름이 유일한 기초지자체만 인식해 홈페이지와 예산 검색에 적용하도록 개선했다. 실제 로컬 자료에서 해운대구 홈페이지 1건과 예산행 1건 및 연결 후보를 확인했다. 전국에 같은 이름이 여러 곳인 `중구`는 하나로 임의 지정하지 않는다.

광역 지역을 함께 적은 `부산 중구 청년`, `서울 중구 청년`은 각각 부산과 서울 중구로 인식하도록 보완했다. 실제 예산 색인에서 각각 5행과 3행이 해당 광역 지역으로만 반환되는 것을 확인했다. `중구 청년`처럼 광역 지역이 빠진 경우에는 지역을 임의로 선택하지 않고 가능한 광역 지역 목록을 검색 및 연결 결과에 표시한다. 행 수는 독립 사업 수가 아니다.

광역 지역이 없는 중복 지명은 이름을 사업명 검색어로 남겨 누락되던 문제가 있어, 같은 이름의 기초지자체를 수록 자료 범위에서 모두 검색하고 각 결과의 광역 지역을 구분하도록 보완했다. `동구 장애인 출산지원금`으로 울산 동구 홈페이지와 예산 연결 후보를 찾고, `중구 청년`으로 여러 중구에 해당하는 예산행을 찾았다. 이는 수록된 자료 범위의 결과이며 모든 지자체 자료가 수집됐다는 뜻은 아니다.

동두천시 지역아동센터 안내는 `지원대상` 대신 `이용아동`을 사용해 상세 안내 추출에서 빠졌다. 사업 제목과 고유 본문, 사업내용 등 기존 확인 조건은 유지한 채 대상 표현을 추가했다. 보관된 [동두천시 원문](https://www.ddc.go.kr/ddc/contents.do?key=445)에서 이용아동·사업내용·신청 절차를 대조해 로컬 목록에 추가했고 연결된 로컬 MCP 검색을 확인했다. 관련 예산은 운영비·인건비 등 여러 세부 행이므로 홈페이지 안내와 일부 이름이 겹치는 후보일 뿐, 한 사업 예산으로 합산하지 않는다. 현재 홈페이지의 실시간 상태는 별도로 확인하지 못했다.

보관된 [울산 동구 장애인 출산지원금 안내](https://www.donggu.ulsan.kr/donggu/contents/contents.do?mId=3030602)를 로컬 목록에 추가했다. 안내에는 울산시와 동구 지원금을 합산해 지급한다는 내용이 있어 출처별로 별도 사업이라고 단정하지 않는다. 2026 예산행은 `장애인가정 출산지원금 지원사업`으로 이름이 달라 `장애인`과 `장애인가정`의 명칭 차이를 표시한 연결 후보로 반환하도록 보완했다. 대상과 범위는 원문 대조가 필요하며, 홈페이지는 보관된 자료 기준이다.

보관 원문을 대조해 사하구 자립수당, 남동구 청년월세, 통영시 아동 지원 안내 세 페이지를 로컬 목록에 추가했다. 사하구의 구비 추가 지급과 남동구의 연령별 신청 경로를 원문과 함께 보존했고, 통영시의 여러 세부 내용은 하나의 페이지 범위로 유지했다. 통영시 검색 검증 중 `경남 통영시`가 홈페이지 검색에서 누락되는 문제가 확인돼 예산 검색과 같은 광역 별칭 처리로 수정했다. 실제 자료의 세 질문과 통영시의 잘못된 광역 지역 제외, 긴 본문 이어보기를 확인했다. 연결된 기존 MCP에서는 정식 지역명으로 통영시 검색을 확인했으며 별칭 수정은 MCP 재시작 후 적용된다.

세 질문에서 홈페이지와 예산행의 이름이 달라 관련 근거가 누락되어 보완했다. 검색어가 홈페이지 사업명의 핵심이고 같은 지자체 예산행의 낱말 시작에도 나타날 때는 관련 명칭 후보로 표시한다. 홈페이지 제목이 포괄적이고 본문에만 주제가 있으면 동일 사업이 아닌 페이지 주제 참고자료로 표시한다. [사하구 예산서](https://saha.go.kr/portal/Downfiles/2026/6-25.pdf) 12~13쪽의 자립수당 일반·구비 행, [남동구 예산서](https://www.namdong.go.kr/com/common/download.do?path=/main/administration/budget/finance/status/2026/00/GA/expenditure/&fn=5.+%EC%9D%BC%EC%9E%90%EB%A6%AC%EC%A0%95%EC%B1%85%EA%B3%BC.pdf) 4쪽의 연령별 청년월세 행, [통영시 예산서](https://www.tongyeong.go.kr/Download.do?key=info.budget&name=35-19.%EC%97%AC%EC%84%B1%EA%B0%80%EC%A1%B1%EA%B3%BC.pdf) 14쪽의 가정위탁 관련 두 행을 직접 열어 확인했다. 각 행은 별도로 유지하며, 예산액을 개인 지원액으로 바꾸거나 행을 자동 합산하지 않는다. 새 MCP 프로세스에서 세 질문 각각 관련 후보 2건을 확인했다.

일반 질문 도구 `research_policy`도 설정된 로컬 홈페이지 자료를 검색해 `municipalEvidence`로 반환하도록 연결했다. 정보공개포털 문서나 예산행과 별도 출처로 유지하며, 결과는 최대 5개 발췌와 원문 위치·검색 범위·이어보기 정보로 제한한다. 실제 MCP 실행에서 `인천 남동구 청년월세 찾아줘`, `부산 사하구 자립수당 찾아줘`는 각각 포털 검색, 홈페이지 1건, 예산 후보 2행을 함께 반환했다. 포털 연결 실패를 모의한 세 질문에서도 홈페이지와 예산 후보가 유지됐다. 홈페이지 원문은 저장 자료이며 새로 확인한 실시간 문서로 취급하지 않는다.

일반 질문 응답에 홈페이지·예산 연결 후보도 제한적으로 포함했다. 검색어별 최대 두 쪽 조합을 대조하고 최대 다섯 연결을 보여주며, 생략과 다음 조회 방법을 기록한다. 예산행은 각각의 금액·연도·원문 위치를 보존하고 페이지 전체 주제 참조는 동일 사업으로 바꾸지 않는다. 포털 실패를 모의한 사하구 자립수당·남동구 청년월세·통영시 가정위탁 질문은 각각 관련 예산행 2개를 별도로 반환했다. 실제 포털을 사용한 남동구 청년월세 MCP 호출에서도 홈페이지 1건과 예산 연결 후보 2행이 함께 반환됐으며 약 17.7초가 걸렸다.

전국 질문에서 홈페이지 첫 20건이 한 지역에 몰리는 문제를 줄이기 위해 검색어당 최대 세 쪽을 확인하고 지역을 우선해 최대 다섯 건을 제시하도록 보완했다. 예산 대조도 확인한 지역·검색어 중 최대 다섯 조합에 대해 각각 두 쪽까지 수행하며, 미대조 지역과 이어보기 인수를 반환한다. 로컬 `청년월세` 대조에서 기존 한 지역 대신 사상구·칠곡군·양주시의 예산 연결 후보가 나오고 미대조 남동구를 이어보면 두 예산행이 나온다. 이는 저장 자료 중 제한적으로 확인한 결과다. 페이지 실패나 저장 자료 변경 시에는 기존 결과를 보존하되 첫 쪽부터 재검색하도록 표시한다.

응답 길이 제한에 걸릴 때 홈페이지 본문 중복을 먼저 줄이고 출처와 예산 연결 후보를 우선 보존하도록 조정했다. 혼잡한 응답을 만드는 회귀 검사에서 출처·이어보기·예산 연결이 남고 원본 자료는 수정되지 않는지 확인했다.

2026-11-06 전국 청년월세 실제 질문에서 개선 전 총 248.4초 중 검색 19.5초, 읽기 228.3초였다. 6개 문서의 제공기관 첨부 요청이 시간 초과됐다. 자동 조사에 한해 파일 요청 대기를 10초로 제한하고 같은 문서의 나머지 첨부는 보류·재조회 대상으로 표시했다. 개선 후 같은 질문은 총 92.0초, 검색 19.2초, 읽기 72.3초였다. 두 실행 모두 원문 요청은 시간 초과여서 내용 읽기 성공을 검증하지 못했다. 느린 정상 응답은 자동 조사에서 보류될 수 있으며, 명시적 문서 원문 조회는 기존 25초 제한으로 재시도한다. 전체 회귀 검사를 통과했다.

자동 원문 조회에서 제공기관 파일 요청이 시간 초과된 문서는 출처 목록에 실패 사유, 보류한 첨부 수와 `research_open_document` 재조회 인수를 함께 저장한다. 실제 괴산군 청년월세 교부 문서에서 시간 초과 후 메모리 시험 저장소의 새 인스턴스로 복원되는 것을 확인했다. 별도의 자동 검사에서는 암호화 보관, 새 인스턴스 조회와 기존 저장 자료 호환성을 확인했다. 원문은 읽히지 않았으며 이 표시는 읽기 성공을 뜻하지 않는다.

출처 목록의 재조회 안내에 연결 중단과 제공기관 점검을 추가하고 처음 검색의 OCR 사용 여부를 보존했다. 공개 여부가 충돌하는 결과와 일반적인 본문 미추출은 일시적 연결 오류로 바꾸지 않는다. 실제 괴산군 청년월세 문서에서 요청 시간 초과 후 메모리 시험 저장소의 새 인스턴스가 OCR 제외 재조회 인수를 반환했으며, 원문은 읽히지 않았다. 연결 중단·점검·비공개 충돌 구분과 암호화 보관 복원은 자동 검사로 확인했다.

동일한 문서가 여러 번 조사된 경우 출처 목록에 마지막 읽기 상태와 이전 텍스트 추출 여부를 따로 기록한다. 예전 텍스트 추출은 현재 공개 상태나 최신 내용을 보증하지 않는다. 실제 괴산군 청년월세 교부 문서를 두 번 조회했을 때 모두 시간 초과됐고, 메모리 시험 저장소의 새 인스턴스에서 조사 횟수 2와 재조회 안내가 유지됐다. 읽기 성공과 실패 순서별 이력은 자동 검사로 확인했다.

특정 지역 질문의 홈페이지 수록 범위를 전국 저장 자료와 구분해 표시한다. `scope.totalSources`는 전체 로컬 출처 수이고 `scope.selectedRegion`은 지정 지역의 출처·지자체·미처리 항목 수다. 홈페이지 검색뿐 아니라 일반 질문과 예산 대조에도 전달한다. 실제 인천 남동구 청년월세 자료에서 전체 61개 출처 중 해당 지역 4개, 관련 예산 후보 2행을 확인했다. 선택 지역에 저장 출처가 0개여도 해당 사업이 없다는 뜻은 아니다.

구미시 공식 게시판의 공공누리 제1유형 게시글 두 건을 추가했다. [산후조리비 안내](https://www.gumi.go.kr/hyeonggok2/board/post/view.do?bcIdx=1&idx=815868&mid=0201000000)는 2025년 사업 내용이고, [2026년 구미형 청년월세 안내](https://www.gumi.go.kr/portal/board/post/view.do?bcIdx=1&idx=834701&mid=0401020000)는 신청 조기마감 공지다. 게시일·연도·마감을 보존하고 현재 시행 여부를 추정하지 않는다. 고유 제목·게시일·본문과 제1유형 표시가 확인된 구미시 게시판만 추출하며, 중복 구조·표시 누락·미확인 내용은 제외한다. 원문은 로컬 검색 파일에만 보관하고 저장소에는 포함하지 않는다. 기존 61개 출처를 유지하며 2개를 추가해 63개 출처가 됐고, 원문 해시·내용과 새 로컬 MCP의 실제 두 질문을 검증했다. 춘천과 구리 자료는 페이지 이용 표시를 확인하지 못했고 부평구는 robots에서 차단해 추가하지 않았다. 성남·안산 후보는 구조가 확인되지 않아 보류했다.

성남시 [경기도 산후조리비 종료 안내](https://www.seongnam.go.kr/bbs010101/405225)의 공공누리 제1유형 표시와 원문을 확인해 추가했다. 공지에는 2026년 10월 1일 종료 예정과 별도로 2026년 9월 30일 공문에 따른 접수 연장 문구가 함께 있어 두 내용을 모두 보존한다. 연장 종료일은 원문에 없으므로 추정하지 않는다. 등록일은 게시글 최초 등록일이며, 연장 문구의 게시 수정일로 해석하지 않는다. 기존 63개 출처를 보존해 로컬 자료는 64개다.

안산시 [경기도 산후조리비 안내](https://www.ansan.go.kr/iloveyou/sub/contents.do?c1=3&c3=22)의 공공누리 제1유형과 본문을 확인해 로컬 자료에 추가했다. 안내에는 출생아당 50만원과 대상·신청기간이 있으나 기준 연도가 없어 현재 접수 여부를 확정하지 않는다. 경기도 사업의 종료·접수 연장에 관한 성남시 별도 공지도 유지하며, 지역별 접수 현황을 하나로 단정하지 않는다. 고유 본문과 출처를 검증했고 새 MCP 호출에서 검색했다. 기존 64개 출처를 보존해 총 65개다.

공공누리 제1유형과 원문 해시를 확인한 구미 2건·성남 1건·안산 1건의 검색 자료를 `data/municipal-kogl1-20261106.json`에 별도 보관하고 작성기관·출처·이용조건을 `data/README.md`에 기록했다. 이 네 건 파일을 지정한 새 MCP에서 네 질문의 원문 링크가 각각 반환됐다. 기존 로컬 65개 출처를 대체하지 않으며, 이 네 건 외의 로컬 자료는 저장소에 포함하지 않았다.

로컬 남동구 홈페이지 네 원문의 해시와 공공누리 출처표시 이미지 대체문구를 대조해 청년자격증·청년농업·청년어촌·청년월세 안내를 저장소용 자료에 추가했다. 작성연도는 원문에서 확인하지 못했으며, 최신 운영 여부를 이 자료만으로 확정하지 않는다. 네 건을 더해 저장소용 자료는 8개 출처다.

별도 설정이 없으면 저장소에 포함된 공공누리 자료 8개를 자동 연결한다. 사용자가 `POLICY_MUNICIPAL_CATALOG`로 지정한 파일은 기본 자료보다 우선하며, 지정한 파일이 잘못되면 자동으로 8개 자료로 바꾸지 않고 오류를 반환한다. 검색 범위는 `scope.dataset`으로 기본 예시와 지정 자료를 구분한다. 실제 PC에서 기본 8개와 지정 65개가 각각 선택되는지 확인했다.
